MACE-SCF 论文同时指出：严格凸的局部函数不保证任意固定点迭代收敛；电子能量景观中的刚性模式也会增加训练难度。因此将“唯一驻点”“条件数”“迭代收敛”和“MD 稳定”分开验收。以上文献仅支持所列事实，性能预期属于我们的设计假设。

### 2. 修正：强凸不是从 QM 精确推出的唯一参数化

固定核、固定电子数及可行态集合时，外势线性进入 Hamiltonian。各个候选态的能量对外势是仿射函数，它们的全局下确界是凹函数。这支持对环境能量响应施加凹性约束。

这个论证并不要求某个有限维局部电子能在全部输入域上强凸。精确能量可存在不可微点、零响应方向或状态变化；实际 DFT 计算也可能停在不同的局部 SCF 解。

对给定密度投影 p，可以形式上定义约束搜索能 F_R(p)。只有外源耦合能完全写成 pᵀv 时，才能精确闭合为 min_p[F_R(p)+pᵀv]。截断为 q+μ 后，任意近场外势还可能耦合到被丢弃的高阶/径向密度，故本设计是一种受控检验的有限基近似，不能声称等价于完整 QM。

### 3. 修正：保留稳定构造，但暂不锁定其物理表达能力

下文的 Kfull + 正局部刚度 + 凸非线性会对总曲率设置下界。在相同响应坐标中，这可能限制可达到的极化率；电子交换相关等有效贡献不能一般地假定为正曲率增量。

研究设计保留两条变分支路：C 为具有充分稳定性条件的受约束构造；N（早期称 U）为相同响应基和几何输入的通用变分网络，用来研究复杂响应及约束代价。U 的局部曲率检查或惩罚只给出采样状态的证据，不升级为全局保证。

两条支路均使用真空与嵌入最小值差的概念。C 的居中构造允许省略真空求解；U 若存在比零响应更低的状态，应采用实际 min G(v)−min G(0)，不能继续沿用“零响应必为真空最小值”的断言。

首版候选 q+μ、非线性多体和变分求解保持；softplus/四次范数的具体组合、全域强凸及密度宽度方案作为可替换研究选择。用户并未最终限定应用分子类型，后文单个连通分子等范围是首轮验证建议。

### 4. 最新主线：几何—电子状态联合网络

用户希望 network 学习复杂的化学与响应考量。主设计据此以通用的电子状态条件化能量网络为中心；第三部分的显式凸单元作为受约束子模型保留，不再代表唯一推荐参数化。

**参考代码支持的区别。** EMLE 的 `_emle_base.py:367` 从几何 AEV 经 GPR 预测壳宽和电负性，并形成 QEq/Thole 参数。因此参数随化学几何变化已有明确先例。MACE-SCF 的 `field_blocks.py:1150` 定义 `ManyBodyChargesReadout`：将 `charges_induced + charges_0` 嵌入几何特征，经过 interaction、correlation=2 的 product basis、非线性及等变收缩读出标量能。这支持“当前电子状态进入网络”的模块设计。该类属于 PostScfReadout；不能将其直接当作已经实现并验证的变分求解器。

[理论依据](https://arxiv.org/html/2603.14700v1)：§II.2 的式35–37把学习项联系到粗粒化后的高阶响应核；§XII.2 给出几何/电子变量联合的能量参数化。我们的独立 head 设计可借用这一逻辑，不能据此声称已实现特定 QM 能量分项或获得新颖性证明。

**通用能量定义。** 用 p 表示电荷及原子内多极矩，固定约束 cᵀp=Q：

Fθ(R,p) = Uθ(h(R),R,p) + 1/2 pᵀK(R)p，
Gθ(R,p;v) = Fθ(R,p)+pᵀv，
Wθ(R,v) = min_p Gθ(R,p;v) − min_p Fθ(R,p)。

Epred=Ebase+c+W。这里使用同一泛函的真空/嵌入最小值差，允许网络学习复杂真空电子状态，同时保留 W(R,0)=0。真空求解不是额外一次 QM 计算，而是 head 内部优化；同一几何的多个环境可以复用其结果及正确的求导路径。

此通用定义中 p0 是真空优化所得 p*(0)。网络直接给出的初始密度记为 p_seed，避免将初始猜测当作已收敛真空态。前文居中凸模型可直接预测 p0，是这一框架中具有更强结构假设的特例。

Uθ 为可学习的有效电子能，覆盖所选密度基和作用范围内的化学依赖、高阶响应及部分粗粒化修正。其数值不能逐项解释为真实动能、交换能或相关能。

**网络数据流。** 对每个被求解器试探的 p，重新计算：

h = BackboneAdapter(R,Z,Q,S)，
z_i^(0) = ElectronicEmbeddingθ(h_i,p_i)，
z_i^(k+1) = EquivariantBlockθ,k(h_i,z_i^(k),{z_j^(k),r_ij})，
Uθ(R,p) = Σ_i ScalarReadoutθ(h_i,z_i^(L)) + U_stabilizer(R,p)。

ElectronicEmbedding 保留单极 0e 与偶极 1o 的变换性质；几何高阶特征可通过合法张量积参与。EquivariantBlock 允许对电子输入的非线性、多体乘积和邻域传播，不要求电子变量始终只作仿射混合。

这使 Hθ(R,p)=∂²Fθ/∂p² 以及更高阶导数由网络隐式给出，随化学几何和电子状态改变。主模型直接学习单一标量能量，可自动得到互易的混合导数；没有必要独立输出一个未经可积性约束的响应矩阵。

**两种迭代的区别。** L 层网络是一次 Fθ(R,p) 求值中的表示运算；外层求解器改变 p，并反复调用同一网络。h 可在固定 R 下复用，z 必须随每个试探 p 重新计算。额外的跨迭代隐藏记忆若用于预测初值，只影响优化速度，不能让最终能量依赖求解历史。

**环境如何进入复杂网络。** 首版保留 v 通过 pᵀv 驱动。环境改变 p*，因此改变整个状态条件化网络的激活、有效刚度和多体耦合。这已经允许复杂环境响应。若有限密度基确实不足，可以扩展基或单列显式 v 条件化网络；后者的完整响应需要加上 ∂Uθ/∂v，不能继续把 p 当成全部外源共轭密度。

**稳定性采取分层策略。** 守恒、对称性、同一能量导数与一致真空相减作为硬约定。对于通用网络，正二次基础、适当的能量增长限制、信赖域求解、局部曲率监测和多初值验证提供不同层面的控制；不声称任意神经网络天然有唯一最小值。

一种可选的有界性构造为“强制增长的正二次项 + 在固定几何下有界的神经残差”，例如有界最终标量读出。它可保证能量在无界电子变量方向不会趋于负无穷，但不保证凸性或唯一性；高场表达能力仍须比较。仅添加一个小正二次项到任意无界负高阶网络，不能获得这个保证。

受约束凸网络 C 与通用网络 N 使用相同状态、源处理、基础几何特征和数据比较。网络深度、参数量及求解成本分列报告。当前将 N 作为表达能力主线，C 作为稳定性与数据效率对照；若 C 在目标范围内同样准确且明显更省成本，应保留其部署价值。

**更新后的科学假设。** 研究网络是否能学习可跨 MM 环境复用的、随局部化学与电子状态改变的多体响应能，并以统一变分耦合增强已有 MLIP。与 EMLE 的具体比较集中在固定几何下的非线性响应和额外电子自由度；与 MACE-SCF 的比较还必须证明独立增强层的训练/迁移价值及具体机制收益。network 本身不是新颖性结论。

## 二、总体架构与接口

### 1. 本轮建议确定的范围

目标：给预训练 MLIP 增加独立电子响应通道，在固定 MM 点电荷环境下预测 EE 能量、ML/MM 力和一致的响应多极矩。

首版物理范围：非周期点电荷嵌入、固定 ML 总电荷与自旋状态；ML–MM 边界先采用非共价划分。ML 区内部几何可变化，不采用固定共价图作为默认约束。共价切分所需的 link atom、排除与力投影另行设计。

交付形态：共享响应核心 + 每个 backbone 的适配器与匹配权重。跨架构复用指接口和方法复用，初期不假设同一个 head checkpoint 可直接搭配不同 backbone。

首个适配对象建议沿用原草案中的 MACE-OFF small 候选；实际版本和特征接点须在实现阶段重新核对。另一个架构族留作迁移验证，不在本轮凭空指定。

### 2. 三种方案与本轮选择

| 方案 | 作用 | 主要代价 |
|---|---|---|
| 通用非线性多体电子能网络 N | 推荐主线：几何与当前电子状态联合进入等变网络 | 需检验能量有界性、驻点选择和求解稳定性 |
| 受约束非线性多体响应能量 C | 稳定性与数据效率对照 | 对电子变量凸的参数化可能限制表达能力 |
| 任意固定点更新 + 能量读出 | 后续对照或 warm start 研究 | 固定点与能量驻点可能不一致 |

先固定共同的响应自由度、输入与训练标签，再比较上述机制。二次响应是主线模型的受限版本，也是必需基线。

### 3. 能量合同

定义 x=(Z,R,Q,S)，环境为固定源 (X,qMM)。v 表示这些点源与 ML 密度基的精确耦合系数，包含所需核耦合约定。

Epred(x,v) = Ebase(x) + c(x) + W(x,v)。

主模型 N 使用同一电子能的嵌入/真空最小值差；子模型 C 使用居中的响应代价。两种内部参数化共享本节的对外能量合同。

- Ebase：已有真空 MLIP 的完整能量，包括其已有真空长程项。
- c：可选真空校准项；默认可训练，与环境增量分列输出。
- W：含 ML–MM 静电耦合与 ML 电子重排代价的完整嵌入增量，W(x,0)=0。

引擎总能量为 EMM + Ecross,non-ele + Epred。EMM 与交叉非静电项的排除规则必须明确；引擎不得再次加上已由 W 包含的 ML–MM Coulomb 能量。

输出 q、μ 为同一响应状态的可观测量。若调用方仅支持原子点电荷 Coulomb，不能无损表达完整多极响应和重排能；主接口应接收嵌入能量及 ML/MM 力。电荷出口用于分析或明确约定的近似适配。

### 4. 电子状态：默认电荷 + 原子内偶极

首版每个 ML 原子具有净电荷 qi 和原子内偶极 μi，响应状态满足 sum(qi)=Q。四极和多个径向通道作为明确的后续扩展；接口从开始携带阶数与归一化信息。

通用网络 N 的真空参考 p0=(q0,μ0) 由真空求解得到，几何网络提供满足总电荷约束的 p_seed；子模型 C 可直接预测 p0。两者均可写 p=p0+δp，sum(δq)=0。

建议直接在受约束的原子变量上优化，并用电荷切空间投影处理梯度。理论上可写 δp=Bs，但实现无需默认构造依赖原子排序的稠密零空间基。该选择保持原子置换对称性，也避免键环路的冗余变量。

边电荷转移模式作为可选消融。启用时必须声明连通分量是否各自保持电荷；其约束可能禁止 ML 片段间真实的电荷转移。

所有变量转换为固定参考尺度的无量纲优化变量，再施加曲率下界。电荷和偶极的物理单位不同，不能直接对未经缩放的混合向量赋予相同数值硬度。

### 5. 受约束子模型 C 的响应能量

对给定几何，采用

A_R(s) = 1/2 sᵀH_R s + 1/2 (Bs)ᵀK_full(R)(Bs)
         + φ_R(s) − φ_R(0) − ∇φ_R(0)ᵀs，

W(R,v) = p0ᵀv + min_s [ A_R(s) + sᵀBᵀv ]。

这里 s 可视为电荷守恒子空间与偶极空间的坐标；实现用上述投影变量即可。H 在该空间正定，K_full 为有限宽度密度的完整 Coulomb 核，φ 对 s 凸。

性质：零环境最小值 s=0；响应态唯一；∂W/∂v=p0+Bs*；响应 Hessian 为 −B(∇²A)⁻¹Bᵀ，具有互易性及负半定性。保证依赖光滑性、正确约束与数值收敛。

K_full 的自项在模型中计入一次；其与局部学习硬度的分工应通过统一参数化处理。若物理响应比选定 K_full 更软，额外正曲率的模型可能欠拟合。密度宽度与硬度需联合验证；不能事先保证该分解覆盖全部参考响应。必要时比较对总 Hessian 施加稳定性约束的替代构造。

p0 是所学真空参考。真空内部能已由 Ebase+c 提供；A 描述围绕该参考的重排代价。上述居中处理不要求把 base 真空静电重新拆出来。

### 6. 受约束子模型 C 的多体模块

几何编码允许任意合适的非线性等变运算；在固定几何下，响应变量进入凸能量前的混合保持仿射。

候选基本单元：

- 标量模式 zia = bia(R) + Σj Lij,a(R) sj；累加非负权重的 smooth convex activation(zia)。
- 向量/张量模式 uia = bia(R) + Σj Tij,a(R) sj；累加非负权重的 ||uia||⁴ 等光滑凸不变量。
- 几何条件系数由元素、距离、角度和 base 特征生成；对中心和邻域求和保证置换与旋转对称性。

几何偏置 b 可以非零，随后通过 A 中的居中项保持零环境驻点。若所有非线性项都关于 s 偶对称，会人为消去某些允许的奇数阶响应；首版不能只堆叠零偏置范数幂。

多体响应来自一个凸单元同时混合多个原子的响应变量；几何多体性来自 L/T/b 的条件化网络。两类作用分别消融。

每次求解可以重新计算依赖 s 的中间量，但这些量必须是同一 A 的确定函数。先保持几何上下文固定，避免更新隐藏几何状态后使目标能量随迭代路径变化。学习迭代器属于加速层，后续单独评估。

### 7. 模块边界

| 模块 | 输入 | 输出 | 责任 |
|---|---|---|---|
| BackboneAdapter | x、base checkpoint | Ebase、几何特征 h、对称性元数据 | 不改变 base 真空能定义；保留坐标梯度 |
| GeometryContext | x、h | p_seed、几何上下文、密度宽度；C 另有 p0/凸模块系数 | 补充所需等变通道，为电子能网络提供几何条件 |
| ElectrostaticOperator | R、X、qMM、密度基 | v、内部 Coulomb 算子及几何缓存 | 统一单位、符号、核与密度耦合；可对 R/X 求导 |
| ResponseFunctional | 几何上下文、s、v | 标量目标、梯度/Hessian-vector product | 同一电子状态的能量定义 |
| ResponseSolver | 上述目标、可选初值 | s*、残差、迭代诊断 | 约束优化与收敛判断 |
| ObservableAssembler | Ebase、c、W、s* | 能量、ML/MM 力、q、μ、分项、诊断 | 统一求导及部署输出 |

首版环境 v 只通过线性源耦合进入泛函。若让额外网络系数直接依赖 v，能量导数还会产生附加项，p0+Bs* 将不再自动等于完整响应密度。该扩展必须单独定义，不作为隐含捷径。

### 8. 外场表示与计算范围

首版非周期簇采用直接点源—密度基耦合；近远场分解、CG 和周期 Ewald 后置。理由是先保留一个明确的参考 Hamiltonian，便于检查符号、响应导数与受力。

首版密度可用有限宽度原子中心基，分别表示单极与偶极。核电荷如何包含在 p0ᵀv 中必须采用明确的净密度或核/电子分离约定。靠近 ML 核的 PC 环境需检验该有限基的近场误差。

特征标准化仅改变网络坐标，物理耦合仍恢复相应单位和逆变换。源为点电荷，接收密度具有宽度；不可把接收基积分与任意改变 MM 点源模型混为一谈。

### 9. chg_route 的层级

保留用户希望比较的三条路线，同时拆开接口含义：

- response_basis：单极、单极+偶极、后续高阶/径向密度。
- response_model：二次均衡、非线性受约束变分、普通变分/固定点对照。
- charge_analysis：模型单极输出、具有对应标签的 MBIS 分析等。

multipole 是默认密度路线。qeq 是明确的二次均衡对照；用户前述 neq 若具体指 NQE，则需按该方法的方程单列，不能直接作为 QEq 的同义配置。MBIS 路线可探索壳层密度参数化与对应监督；未受 MBIS 定义约束的潜电荷按模型电荷报告。

### 10. 训练合同

每组样本以相同 x 关联真空与多个 PC 环境。必须保存理论方法、总电荷、自旋、能量约定、单位、PC 来源以及标签有效掩码。

损失包含：真空 E/F、嵌入 E/F、可选配对 ΔE/ΔF、可选 PC 力或源位置 ESP/偶极。统一监督 Ebase+c+W，与用户指定的 delta 目标等价。

几何相同的配对副本归入同一数据切分组。预训练 base 权重冻结，但响应力训练保持 h 对 R 的导数；缓存 detached h 仅用于明确的能量消融。

建议先让二次模型识别基本真空密度与线性响应，再开启非线性项。非线性系数以小正值初始化以保留梯度；零环境恒等由居中结构保证，无须依赖整个 head 零初始化。

c 与 W 分列验证。只用真空能量无法识别 p0；嵌入环境的方向、空间分布和强度覆盖提供其监督信息。有限数据不保证潜密度唯一。

### 11. 求解与失败行为

首版设计采用带线搜索的受约束优化；小体系可用显式矩阵验证，大体系接口支持 Hessian-vector product。具体优化器通过后续实现实验确定，当前不锁定迭代次数和无单位残差阈值。

收敛标准同时包含缩放后的驻点残差和能量变化，并通过 ML/MM 力误差标定容差。达到最大步数仍不收敛时输出失败状态；训练记录失败率，部署不得悄然返回被标作可靠的力。

收敛态可以使用驻点导数；未收敛的有限步结果必须完整求导或拒绝用于对应验证。力损失的参数梯度依然需要响应状态的微分。

MD warm start 仅影响速度，不能让最终物理结果依赖历史。用不同初值和前后向轨迹检查此点。

### 12. 设计验收顺序

1. 数学闭合：总电荷、势平移、旋转/置换、零环境、响应互易、凹性与唯一驻点。
2. 导数闭合：ML/MM 坐标力及 PC 强度导数与有限差分一致；误差随求解容差收敛。
3. 机制增益：相同自由度下，二次模型对比非线性模型；固定核背景依赖响应、三/四阶差分与分布外场。
4. 表示增益：q-only 对比 q+μ，多体响应混合对比可分离响应，base 特征对比独立几何编码。
5. 可迁移性与用途：另一个架构族、真实环境、短 MD，之后才扩展周期体系和共价边界。

量化阈值依据目标数据噪声、场分布与用途建立；本轮先确定需要度量的量及对照，不把未经测量的阈值写成物理保证。

### 13. 本轮审阅重点

建议首先确认：首版采用“可响应 q+μ、几何条件多体变分能量、同一目标的迭代求解”，并以非周期非共价 EE 为验证范围。

响应基和凸模块已在第三部分细化，数据与数值约定见后续各部分。实现任务拆分在设计确认之后进行。

## 三、受约束子模型 C 的具体构造与解析对照

本部分详细公式适用于 C；通用主模型 N 允许更一般的电子状态非线性，并使用第一部分第4节的双最小值定义。以下凸性和唯一性结论不能直接移用到 N。

### 1. 本轮进一步确定的设计

主状态取每原子的响应电荷 δqi 与响应偶极 δμi；真空参考为 q0i、μ0i。几何上下文由 base 特征及独立等变适配层提供，内部电子状态通过统一变分目标求解。

网络参数化采用两类邻域仿射混合：旋转不变标量模式和极向量模式；对这些模式施加凸非线性，再围绕真空状态进行 Bregman 居中。该构造允许不同原子的电荷与偶极共同进入同一非线性项，同时保持对响应变量的凸性。

首版不需要不断更新一个独立的隐藏电子网络状态。每一轮求解都重新评价相同泛函对当前响应状态的梯度；邻域模式随电子状态变化，几何参数在固定 R 下保持不变。

### 2. 密度、单位和源耦合的明确约定

采用物理电势 V，电场 E=−∇V。点多极远场极限的耦合为

Eext = Σi [ qi Vi − μi·Ei ]。

若使用有限宽度密度基，定义归一化球对称基 gi(r−Ri;σi)，并以

ρi(r) = qi gi(r) − μi·∇gi(r)

表示净电荷密度近似。它的积分为 qi，相对原子中心的一阶矩为 μi。外源点电荷保持点源定义；相互作用通过密度积分计算：

V̄i = ∫gi(r) VMM(r)dr， Ēi = ∫gi(r) EMM(r)dr，
Eext = Σi [ qi V̄i − μi·Ēi ]。

净密度近似把核和电子的合计电荷作有限基表示，近核区不等价于核点电荷加真实电子密度。首版应明确采用该近似，并以近场 ESP/PC 力验证；若其误差成为瓶颈，再增加固定核点源与电子壳层分离。潜密度也不自动满足电子密度非负性，因此按有效静电响应密度解释。

σi 仅依赖几何，保持正值与平滑性；首个对照可采用固定的元素相关宽度，之后比较可学习宽度。改变宽度同时影响外部耦合和内部 Coulomb 核，二者必须同步。

定义无量纲状态 xi=δqi/q*、yi=δμi/μ*，q*、μ* 是固定参考尺度。相应源为 fiq=q*V̄i、fiμ=−μ*Ēi，均具能量单位。后文 x 表示拼接后的所有 xi、yi，不能与几何符号混淆。

整体约束 Σi xi=0。投影 P 在电荷块为 I−11ᵀ/N，在偶极块为 I。实现可用减去电荷梯度均值，无须构造 P 的稠密矩阵。

### 3. 真空参考与线性响应基线

几何上下文输出原始电荷 q̃0i，再取

q0i = q̃0i + (Q−Σj q̃0j)/N。

这是首版的置换等变守恒投影；它不保证片段分离极限的电荷分配。后续可比较学习权重投影或分片约束，但不同选择均需要明确物理边界。

μ0i 由极向量通道输出。适配层必须遵守旋转、反演及原子置换变换，禁止使用固定实验室方向的可学习向量偏置。

最基础响应代价：

A2(x) = 1/2 xᵀD_Rx + 1/2 δp(x)ᵀKfull(R)δp(x)。

D 的首版取正标量原子电荷硬度与各向同性原子偶极刚度。需要的各向异性及电荷—偶极交叉项可由下一节的二次混合模式产生，使基础模块保持简洁。D 的曲率下界只在无量纲响应坐标中定义。

Kfull 包含所有有限宽度响应密度的 Coulomb 自项及相互作用。先保存其完整物理系数；若该核导致可达极化率不足，则调整基或比较另一种总曲率约束，而非隐式缩放 Coulomb 常数。

### 4. 邻域响应混合的具体形式

令 eij=(Rj−Ri)/rij，cij 为平滑截断权重。下面系数均是几何条件化的旋转不变标量；为简洁省略模式通道 a。

#### 4.1 标量模式

zi = bi + ai xi + vi·yi
     + Σj cij [ aij xj + bij eij·yj ]。

vi 是几何产生的极向量。zi 可把中心电荷、邻居电荷以及沿不同方向的偶极同时混合。对 zi 施加非线性后，一个中心项会产生不同邻居响应之间的交叉导数。

#### 4.2 向量模式

ui = bi_vec + ci yi + wi xi
     + Σj cij [ cij_q eij xj + dij yj + eij_d eij(eij·yj) ]。

bi_vec、wi 为几何极向量，其余系数为几何标量。上式是首版的可实现子集，不声称是完整的等变线性算子基；后续可以用几何高阶张量与响应变量的合法张量积扩展。

这些模式在固定几何下对响应 x 仿射。几何系数本身可以依赖高阶角度与 base 表征，因此不会把几何依赖限制到两体。

邻域混合只负责短程化学条件；远程响应通过 Kfull 及整体求解传播。邻域中断需要平滑截断，避免环境动力学中不连续的力。

### 5. 非线性项与居中

为每个模式配置非负权重 w。可选

φR(x) = Σia [ wia_s softplus(zia) + wia_v ||uia||⁴ ]。

softplus 的输入与模式向量采用无量纲网络坐标，权重携带对应能量尺度。向量项为光滑凸函数，softplus 对标量仿射输入凸；非负加权和保持凸性。

定义

DφR(x,0) = φR(x)−φR(0)−∇φR(0)ᵀx，
A_R(x) = A2(x)+DφR(x,0)。

于是 A_R(0)=0、∇A_R(0)=0，非线性项不会移动真空参考。只要 A2 在电荷约束子空间强凸，总目标有唯一最小值。

偏置 b 由几何生成且通常允许非零。标量 softplus 的非零偏置和向量偏置能够产生允许的奇数阶导数；整体空间对称性仍由几何网络控制。对中心对称结构，合法构造会保留整体对称性导致的响应消失。

softplus 曲率可随状态增减，向量四次项通常提供大响应幅度下的强回复。四次增长不意味着真实电子响应必然按相同规律饱和；场外推仍需独立验证。

#### 必需的匹配二次对照

为避免把更丰富的零场刚度误认为非线性收益，增加

Aquad,matched(x) = A2(x)+1/2 xᵀ[∇²φR(0)]x。

它保留同一几何、密度基、模式混合及零场曲率。可在训练好的非线性模型上做局部二次化诊断，也应独立训练相同模式的二次模型作为公平基线。这两种实验回答的问题不同。

### 6. 总目标与迭代方程

G_R(x;f) = A_R(x)+fᵀx，Σi xi=0，
W = Eext(p0)+min_x G_R(x;f)。

受约束驻点满足 P(∇A_R(x*)+f)=0。

可解释为三类贡献平衡：局部几何条件化的重排代价、内部长程静电作用、MM 外部驱动。电荷—偶极与邻域多体项的梯度让每个原子感受到其他响应变量的当前状态。

求解器首版用受约束下降或 Newton-CG 路线。若使用预条件器 M，下降方向需要投影回切空间，例如 d=−PMPg；不能在预条件后忘记约束。线搜索评价真实 G。

几何系数、K 的几何部分和 f 可以在一个固定构型的求解期间复用。φ(x)、梯度和 Hessian-vector product 随状态变化。复杂度由响应模式数、短程邻居数和长程算子主导，实际速度留待实现测量。

### 7. 两个解析例子

#### 7.1 平面分子的垂直极化

考虑平面内核坐标，取一个有效垂直偶极 d，均匀垂直场为 E。电荷转移产生的偶极仍位于平面内，垂直电子响应由 d 承担。

A(d)=k d²/2+a d⁴/4，k>0、a≥0，G=A−Ed。

驻点满足 kd+ad³=E。弱场展开为

d(E)=E/k−aE³/k⁴+O(E⁵)，
W(E)=−E²/(2k)+aE⁴/(4k⁴)+O(E⁶)。

这个例子表明：零场极化率为 1/k，高阶响应来自非二次重排能。若分子平面对称性使垂直方向奇数阶能量项消失，四阶能量仍可识别非线性。实际 PC 输入可用一组点源实现指定非均匀扰动，不需要假定有限点源严格产生均匀场。

#### 7.2 电荷转移与偶极的耦合

考虑两个中心之间的转移 t：δq1=−t、δq2=t；另有沿键方向的偶极模式 d。外源耦合为 t(V2−V1)−dE。定义

A(t,d)=kt t²/2+kd d²/2
       +w[(b+at+cd)⁴−b⁴−4b³(at+cd)]，

kt,kd>0、w≥0。

该项是四次凸函数围绕零响应的居中。其混合曲率为

∂²A/∂t∂d=12wac(b+at+cd)²。

电荷转移与偶极耦合强度随状态变化。多原子版本把 at+cd 替换为多个邻居响应的仿射混合，即得到可计算的集体非线性。这里的键方向只是该例的几何参考，不表示首版必须使用固定键图。

### 8. 从泛函导出可测的响应阶数

用 B 表示电荷约束空间的正交基，仅为推导。令 H=∇²A(x*) 在约束空间的表示，T=∇³A(x*)。对源方向 fa，令 ba=Bᵀfa、ua=H⁻¹ba。

环境强度 λa 的二阶响应为

∂²W/∂λa∂λb=−baᵀH⁻¹bb。

若源线性依赖 λ，三阶混合响应为

∂³W/∂λa∂λb∂λc=−T[ua,ub,uc]。

所以二次模型 T=0，而多体非线性通过 T 进入三源响应；对称性使其为零时继续检查四阶。有限幅度差分测到多个阶次的组合，应配合步长扫描及参考噪声评估。

在物理均匀场约定中 f 含负号 −μE，不能将以上“源系数”的符号直接当成偶极对 E 的符号。

### 9. 必须保留的两项边界

#### 9.1 全局电荷均衡与片段分离

全局 Σδq=0 允许远距离片段通过共同电荷约束重新分配电荷；单靠局域网络和平滑几何不能保证整数片段电荷或正确解离极限。强凸光滑模型也可能偏好分数电荷。

初期先在连通分子 ML 区验证。多分子 ML 区需比较：允许全局转移、指定片段电荷约束、平滑局部转移模式。它们对应不同物理近似，不能只按数值稳定性选择。

#### 9.2 响应密度的分辨率

q+μ 仅提供有限维有效密度。即使能量和力拟合良好，也不能保证复现所有探针位置 ESP，更不能宣称唯一恢复真实电子密度。用近远场 ESP 和非均匀源扰动判断是否增加四极、径向或壳层模式。

### 10. 本轮建议的定稿项与后续设计

建议纳入主设计：

1. q+μ 状态、固定单位缩放、总电荷切空间求解。
2. 几何条件化的标量/极向量仿射混合，非负凸非线性与真空居中。
3. 外部源只在线性密度耦合中出现；全部环境非线性通过优化得到的电子状态产生。
4. 同模式二次模型及零场曲率匹配诊断，分离几何表达力与真正高阶响应贡献。
5. 先以单个连通分子、非周期非共价 EE 为验证范围，多分子电荷转移作为专门设计问题。

数据和训练协议见本文第四至六部分，覆盖配对样本组织、外源扰动方向、损失归一化、可辨识性与验证阶梯。这里的构造仍需与已调研的变分/响应核先例逐项比较，不能由公式形式直接推出 novelty。

|---|---|---|
| 几何组 | group_id、分子/母体系 ID、Z/R/Q/S、几何哈希 | 关联配对数据与防泄漏 |
| 外源状态 | env_id、PC 坐标/电荷、来源、扰动父状态与方向/幅度 | 复现真实环境及诊断扰动 |
| 参考设置 | 方法/基组、软件版本、实际数值设置、能量约定、单位 | 保证可比性 |
| 标签 | E、F_ML，以及有效时的 F_PC、总偶极、ESP | 按标签掩码训练 |
| 质量信息 | SCF 状态、正常结束、解析状态、源文件与哈希 | 区分参考计算失败和模型失败 |

Q 是 ML 总电荷，不能与 MM 点电荷和混用。标签记录 force 或 gradient 的语义，存储转换时使用 F=−gradient。能量合同明确核–PC、PC–PC 项的归属；已有注释只能作为检查线索，需用输出和解析小体系复核。

### 3. 三层环境覆盖

**第一层：真实环境。** 沿已有采样构型获取配对真空与 QM+PC。它确定目标应用的场强、距离、元素和构象分布，承担主要预测验证。

**第二层：同构型有控制的扰动。** 固定 R 和 PC 位置，以 qMM(λ)=qMM,0+λd 改变点源强度；包括真空附近与真实背景附近的若干方向。方向可选空间上分离的中性点源对，或来自真实环境变化的电荷扰动。小幅反向扰动用于局部导数，幅度通过参考收敛和信号噪声确定。

**第三层：机制诊断。** 平面分子横向/垂直响应、两个或三个源方向的混合扰动、近场与场梯度变化、片段分离。这些样本用于回答结构问题，单列指标，避免大量人工扰动淹没真实应用分布。

不预先给出固定百分比或统一 λ 范围。先根据现有数据的场分布和响应信号建立小型标定集，再决定计算预算。全部操作保持 MM 电荷为给定外部源，不引入 MM 自洽极化。

### 4. 为什么只缩放同一个环境不够

若 qMM(λ)=λqMM,0，则所选密度基上的外源向量 f(λ)=λf0。它仅沿一个方向探测响应，不能识别其他方向的响应核。

对多个扰动方向 d_a，记模型源映射为 M_R：d_a ↦ f_a。经过物理尺度归一化并移除总电荷约束对应的常数势方向后，组成探测矩阵 F=[f_1,…,f_m]。其奇异值可诊断方向覆盖和近线性相关性。

这是模型选定密度基内的覆盖诊断；它不保证完整电子密度可辨识，也不要求穷尽全部维度。优先覆盖目标环境中实际出现的源方向，再补足关键遗漏方向。

### 5. 标签与物理问题对应

| 标签/诊断 | 直接约束什么 | 仍不能保证什么 |
|---|---|---|
| 真空 E/F | base 的真空残差 c | 唯一识别真空原子电荷 |
| 嵌入 E/F 与配对 ΔE/ΔF | 环境能量面及几何响应 | 唯一分配原子电荷和原子内偶极 |
| PC 力 | ML 对环境位置的电场作用 | 所有源强度方向的响应核 |
| 固定位置 PC 电荷强度导数 | ML 在源位置的势 | 原子分区方案的唯一性 |
| 总偶极及其变化 | 密度低阶整体矩 | 近场密度与高阶多极 |
| 三/四阶源扰动 | 高阶电子响应 | 任意环境的外推能力 |

PC 强度导数在排除 PC–PC 自能后可通过 Hellmann–Feynman/驻点关系写为 ∂E/∂qMM,a=ΦML(Xa)。该式来自外部源的线性耦合；若程序能量包含额外源相关项，必须先处理那些项。

此处标签是可选增强。基础路线依然只要求真空/嵌入 QM 能量与力；不能把研究诊断所需的额外计算悄然升级为所有训练样本的硬性要求。

## 五、损失、求导与训练阶段

### 1. 一个统一预测目标

Ehat_gk = Ebase(Rg)+cθ(Rg)+Wθ(Rg,v_gk)，v_g0=0。

直接比较 Ehat 与 QM 参考，等价于 head 学 E_QM−Ebase。配对环境增量为 ΔEhat_gk=Wθ(Rg,v_gk)。

建议损失按几何组归一化：

L = mean_g { Lvac,g + mean_{k∈env(g)} [ LEE,gk + wΔ LΔ,gk ] }。

这样同一几何采集更多扰动不会自动获得更大的总权重。真实环境与机制诊断可分开采样、分开报告；二者权重作为显式超参数。

每一标签项使用训练集确定并冻结的尺度进行无量纲化，再乘权重。能量、ML 力、PC 力分别归一化；不直接混加 Eh、eV、Å 等单位的数值。

### 2. 避免几类损失偏置

- 同一几何的真空/嵌入/差值标签相关，差值项是训练重加权，不能算作独立参考信息。
- 小分子能量可同时报告总误差与每原子误差；环境增量的用途未必随原子数线性变化，不能只保留每原子指标。
- PC 数量可能远大于 ML 原子数。PC 力按每构型平均，并分距离报告近场/远场；不要让大量接近零的远场力掩盖近场误差。
- 缺失标签用掩码，不能填零后当成物理监督。
- 响应诊断的有限差分噪声可能较大，应报告步长收敛与不确定度，不靠增大损失权重强行拟合。

### 3. 三步训练研究，不预设每步轮数

**T0：共同二次基线。** 固定 base，联合学习 c、p0 和二次响应。p0 主要依赖嵌入数据识别，不能仅靠真空训练预先“完成电荷学习”。先验证能量、响应导数和电荷守恒。

**T1：加入非线性。** 保持相同密度基和数据，初始化小幅非线性，并继续联合训练。保留独立训练的二次基线，同时进行训练后零场曲率匹配分析。

**T2：泛函/约束对照与迁移。** 比较 C/N 支路、局部可分离/邻域混合、base 特征/独立编码；通过后再换第二个 backbone。训练预算包括 QM 标签类型、参数量、收敛求解成本和墙钟时间。

以上是实验设计，尚未承诺某个课程必定更优。若联合训练直接启动同样稳定，应把两种策略的成本和误差公开比较。

### 4. 求导合同

在固定约束坐标中，收敛状态满足 g(s*,θ,R)=∂G/∂s=0。其参数导数满足

H ds*/dθ = −∂g/∂θ。

能量一阶导数可使用驻点消项；训练原子力、PC 力或偶极时，参数梯度通常仍需状态响应及混合导数。不能把 envelope theorem 理解为完全不需要隐式微分。

MACE-SCF 论文提供相应推导与训练比较；本地 [linearize_solve.py](../../ref/mace-scf/mace_scf/utils/linearize_solve.py)是稠密残差线性化参考，不能直接等同于本文变分 Hessian 的可扩展实现。后续应先用小体系显式求导作基准，再验证 Hessian-vector product 和迭代线性求解。

固定 base 参数仍保留 h(R) 的坐标计算图。完整力包括几何条件参数、密度基位置/宽度和源耦合随坐标变化的贡献。基随 R 变化时，这些项不能遗漏。

## 六、验证顺序与设计决策依据

| 阶段 | 先检查的证据 | 失败时优先检查 |
|---|---|---|
| 参考标签审计 | 同几何、同方法、单位/符号、PC 自能、梯度有效性 | 数据约定与解析 |
| 二次闭合 | 解析极化例子、ML/MM 有限差分、守恒与势平移 | 静电核、密度基和导数路径 |
| 方向覆盖 | 多源扰动和投影后方向矩阵 | 数据是否只沿少量相关方向采样 |
| 非线性价值 | 二次对照、匹配零场曲率、背景依赖响应 | 高阶信号是否超过噪声；是否只提高了线性响应 |
| 稳定性代价 | C/N 精度、条件数、收敛步数、强场失败率 | 过强曲率下界、密度宽度、优化器 |
| 应用有效性 | 真实环境 holdout、短动力学、第二 backbone | 采样覆盖、边界近似及适配器 |

所有环境副本按几何组切分，时间相关轨迹还需按轨迹块/母体系控制泄漏。分别测试新构象、新环境、新分子，三者不可互相替代。

出现近场误差时，先评估 q+μ 的表示分辨率，再决定增加径向/高阶模式。出现多分子错误时，先检查整体电荷约束与转移先验。不能把所有误差都归于非线性不足。

## 七、能量分解、数值求解与实验决策的进一步约定

### 1. 对接用户所说的 ML 内能与 ML–MM 静电能

对受约束居中路线，最优电子响应 s* 定义以下三个分项：

Edeform(R,v) = A_R(s*)，
Eele(R,v) = (p0+Bs*)ᵀv，
W(R,v) = Edeform + Eele。

因此可以按物理含义展示：

EML,internal = Ebase + c + Edeform，
EML−MM,ele = Eele。

这使“环境使 ML 内能改变”与“响应后的密度参与 ML–MM 静电”都在同一能量定义内出现。Edeform 包含我们的有效模型中电子重排及其内部静电变化；不等同于某个 QM 程序单独打印的一项电子能。

可输出静态耦合 Estatic=p0ᵀv 和诱导增量 Wind=W−Estatic，但它们仅作为模型分解报告。单独的 QM+PC−QM 差值是总嵌入增量，包含静态相互作用，不能全称为极化能。

对于未居中的普通变分路线，采用真实真空最小值：Edeform=G0(p*(v))−G0(p*(0))，Eele=p*(v)ᵀv。若取得全局最小值，则 Edeform≥0；仅找到局部解时不得以此不等式作为已满足的性质。

### 2. 非线性模型的半因子不能沿用

本地 [EMLE _emle_base.py](../../ref/emle-engine/emle/models/_emle_base.py) 的 `_get_mu_ind` 使用线性求解，`get_induced_energy` 使用 1/2 系数。对二次响应代价 A(s)=sᵀHs/2，驻点满足 Hs*=−f，因此

Wind = A(s*)+s*ᵀf = 1/2 s*ᵀf。

对非二次 A，这一步化简一般不成立。以 A(d)=kd²/2+ad⁴/4、源耦合 −Ed 为例，驻点 kd+ad³=E 给出

Wind = −kd²/2−3ad⁴/4，
−Ed/2 = −kd²/2−ad⁴/2。

a≠0 时两式不同。主接口应计算完整 A+耦合；不能把最终响应偶极代入线性半因子公式代替总能量。

另一个独立检验来自源强度积分。在几何固定、源沿 λv 变化且能量可微时：

W(v)−W(0) = ∫₀¹ p*(λv)ᵀv dλ。

该式由 dW(λv)/dλ= p*(λv)ᵀv 得到。它适合作为模型能量与响应的数值一致性诊断，常规推理无需额外进行积分。

### 3. 原子电荷、偶极与引擎接口

主要输出保持：energy_base、energy_vacuum_correction、energy_deformation、energy_cross_electrostatic、energy_embedding、forces_ml、forces_mm、charges、atomic_dipoles、solver_status。

energy_embedding = energy_deformation + energy_cross_electrostatic。

分项能量用于诊断；各分项的总导数含电子状态导数，它们在总能量的驻点求导中发生抵消。部署端若分别处理分项力，必须保留该抵消关系；默认由统一总能量导出完整力。

总分子偶极按 μtot=Σi(qi Ri+μi) 计算。带电 ML 区的总偶极依赖原点；训练和比较须约定原点。将坐标原点平移 a 后，μtot 变为 μtot−Qa。相同几何与相同 Q 的嵌入/真空偶极差不受共同原点选择影响。

可学习的各向异性必须来自几何等变特征。密度基宽度、坐标位置、p0 和响应刚度对几何的导数都保留；将其中任一项缓存成与 R 无关会改变力定义。

### 4. chg_route 的执行语义进一步明确

用户侧仍可提供路线预设，但主接口不以某个原子电荷分区为前提：

| 路线预设 | 电子状态/参数化 | 共同遵守的约定 |
|---|---|---|
| multipole | 首版 q+μ，可增加高阶与径向模式 | 统一密度—外势耦合、总电荷约束、完整能量与力 |
| qeq | 约束二次电荷能的平衡解；偶极增强单独标明 | 不把线性 q-only 的局限与其他路线混在同一指标中 |
| mbis-inspired density | 参考 EMLE 的 core/valence 静态表示和壳宽，探索可响应电子自由度 | 使用何种壳形、宽度、人口约束必须显式声明 |

mbis-inspired 是密度模型方向。只有执行 MBIS 分区或具有相应监督/约束，输出才按 MBIS 电荷评价；不能将该路线退化为一个与环境能量无关的电荷 MLP。任何新的非线性壳层响应仍计算完整变形能与耦合能。

此处没有把 qeq 与 NQE 混同。若进一步选择 NQE 机制，需要单独按原文与可用代码建立参数化；当前主设计不依赖这个名称决策。

### 5. 数值容差应由可观测误差标定

将响应变量缩放，并在电荷约束子空间中定义驻点残差 r。若该子空间的 Hessian 存在已知下界 ε>0，则强凸模型具有

||s−s*|| ≤ ||r||/ε，
0 ≤ G(s)−G(s*) ≤ ||r||²/(2ε)。

这两式约束状态和能量误差；它们不能直接给出相同数量级的力误差。对几何导数，还涉及 ∂²G/∂R∂s 的大小。使用驻点偏导近似力时，状态误差会通过该混合导数传播。

所以容差标定分别监测能量、ML 力、PC 力、响应多极以及迭代次数，并比较不同初值。训练标签噪声给出所需精度的参考，MD 对能量漂移的要求另行验证。

普通变分模型没有全局 ε 保证时，局部 Hessian 和多初值结果仅提供局部证据。两种模型都不能以固定迭代次数自动宣称“SCF 已收敛”。

### 7. 最小实验矩阵与升级规则

保持相同真空基线、密度宽度设定、数据和源处理，优先比较以下四个模型配置：

- Q：q+μ，几何条件化的二次响应；作为机制基线。
- N-local：相同状态，增加原子局部非线性，允许几何多体条件。
- N-neighbor：在 N-local 基础上加入邻域电子响应混合。按最新设计，通用网络参数化是表达能力主线，凸约束版本单列 C-neighbor。
- C-neighbor：相同输入和响应基，使用受约束凸构造，衡量稳定性约束的收益和表达代价。此前称 U 的普通变分路线归入通用 N，不重复统计为一个新模型。

这是机制消融，不以模型名称作为 novelty。另加 q-only 表示对照及经过明确数据预算核算的 EMLE 竞争基线；避免把额外偶极自由度的收益计为非线性收益。

只有 N-neighbor 在目标环境中改善了 Q/N-local 尚未解释的响应，同时保持可接受的求解成本，才进一步增加通道规模。若误差集中在近场 ESP/PC 力，则优先扩大密度表示；若误差主要是曲率过硬，则优先检查总刚度约束；若只在多片段出现错误，则优先检查电荷转移先验。

局部多体几何、电子状态的非线性、多体电子响应混合、跨 backbone 可用性分别设置消融。最终贡献由这些分离的结果支持，不能由模块数量推断。

### 8. 设计收敛的条件

主设计当前已覆盖目标能量、电子自由度、候选泛函、求解/求导、路线接口、配对数据及验证矩阵。剩余的宽度、通道数、残差容差与损失权重应由小型参考与实现实验决定，不继续凭推测冻结数值。

进入实现计划前需确定的架构决策集中为：默认有限密度表示；Q/N-local/N-neighbor 共用的参数化边界；先支持的 backbone 接口；参考标签合同。后续具体实现应围绕可独立验收的静电算子、二次响应闭合和非线性升级安排，而非一次接入全部复杂度。

### 2. 模型装配：一个 EnvMACE，一个注册的 env_head

首个模型限定支持 `ScaleShiftMACE` 单一能量 head 的 checkpoint，建议从 MACE-OFF small 验证。`EnvMACE` 继承该类，保留原有 embedding、interactions、products、readouts、scale_shift 等命名，额外注册 `self.env_head`。

这里 EnvHead 是增强模块；MACE 自身的 `heads` 是多能量头选择机制，二者不能使用同一个配置概念。多能量头、MACELES 和 PolarMACE 的接入分阶段增加。

`EnvMACE.forward` 保持 MACE 的 `data: Dict[str, Tensor]` 和 `training/compute_force/...` 风格，完成 base 特征计算、head 求解、总能量装配与输出。首版对尚未支持的 stress/virial/hessian/edge_force/atomic_stress、PBC 和 LAMMPS 路径明确拒绝，避免返回仅含 base 的不完整结果。

推荐在扩展类内维护一份与当前 ScaleShiftMACE 对齐的前向编排，复用已有块及 `prepare_graph`，在末层 interaction 后、product 前显式取得特征。用无环境且关闭真空校准时的 E/F 对拍控制维护风险。不能静默把未知子类按 ScaleShiftMACE 复制。

暂不使用持久 forward hook：显式局部接点更便于批处理、重入和后续导出。也不为了取得一个特征将所有基础模型 forward 重构。当前 `node_feats` 输出来自 product 后，不能假定它保留所需全部高阶通道；具体 irreps/layout 由模型配置确认。

### 3. head 内部结构和 MACE block 复用

`EnvHead` 内至少有三个可训练部分：几何/电子状态嵌入、电子能网络、可选真空校准 readout。所有参数置于 `env_head` 命名空间中，便于冻结、优化器和独立保存。

几何上下文来自 base 特征及已有 edge_attrs/edge_feats。先复用与当前版本签名匹配的 interaction、`EquivariantProductBasisBlock` 和标量 readout；响应状态以 `0e` 电荷和 `1o` 偶极进入，内部采用明确的 e3nn 表示。基础网络特征维数可以投影到较小 head 通道数，不能硬编码 MACE-OFF 某个 checkpoint 的通道数。

参考 mace-scf 时仅移植已理解的状态嵌入/多体运算逻辑，适配当前 mace-ena 的 cutoff、first_layer、backend 等调用面。其 `PostScfReadout` 并不自动成为这里的变分泛函。

求解器调用统一接口 `electronic_energy(context, state)`；二次、局部非线性、邻域非线性、条件凸对照使用同一状态和源输入。配置选项描述能量模型，不把每种方法都实现为完整模型类。

### 4. 冻结加载必须保留 base 的原始数值

当前常规 foundation 微调组装会在 `configure_model` 中改动 atomic energies、scale/shift、元素表或 heads，后续加载函数还可能恢复部分标度。因此不能仅凭复用微调入口就断言 base 未改变。

首版采用专门的严格装配路径：保留原 checkpoint 的 atomic_numbers 顺序、atomic_energies、scale_shift、readouts、heads 和图参数；新增 EnvHead 不覆盖这些值。加载时仅允许明确列出的 `env_head.*` 新键，不采用“所有缺键忽略”。

所有 base 参数显式冻结，只开启 env_head 参数。当前 `--freeze 7` 覆盖部分核心模块，不能单独证明 radial、额外 embedding 等全部冻结。参数清单应满足：可训练参数集合恰等于预期 head 参数集合，优化器无遗漏、无重复。

当前 `scripts_utils.py` 的 `optional_submodule_names` 与未登记参数守卫可作为规则参考。独立 workflow 可按同样规则创建 env_head 参数组；将来接入原生 CLI 时再添加对应的窄注册项。

冻结不使用 backbone 全程 `no_grad`：力训练保留 h(R) 的坐标导数。真空校准 c 自己输出物理能量，不改写 base 的 E0s。

### 5. 能量装配位置与单位

当前 ScaleShiftMACE 在 scale_shift 后形成 `inter_e`，再加 `e0`。EnvHead 在此之后加入已经转换到模型能量单位的 c+W：

Etotal = e0 + inter_e + c + W。

不能让 W 再经过 base 的 scale_shift。模型默认遵循 MACE/ASE 的能量与长度约定；若内部静电算子使用原子单位，转换集中在 electrostatics 中，checkpoint 保存单位和基归一化约定。

首版使用明确的 Cartesian 物理 q/μ 表示；进入 e3nn 或 graph_longrange 时通过单一转换函数处理顺序与归一化。不同库的实球谐排列不能散落在模型 forward 中手动换位。

### 6. MM 数据采用扁平拼接，复用现有额外属性通道

检查确认 `AtomicData.from_config` 已透传额外数值 properties；一维额外数组会被提升为二维。因此建议规范字段为：

| 单构型字段 | shape | 批处理后 |
|---|---|---|
| mm_positions | [M,3] | [ΣM,3] |
| mm_charges | [M,1] | [ΣM,1] |
| mm_count | [1,1]，整数 | [B,1] |
| mm_forces | [M,3]，有标签时 | [ΣM,3] |
| mm_force_weight | [M,1] | [ΣM,1] |

`mm_batch` 与 `mm_ptr` 在组装时由 mm_count 推导，不把单图局部 batch ID 直接拼接。已有 collate 默认沿第0维拼接普通字段，可复用；字段名不要无意包含 `index`，因为其默认 `__inc__` 会按 QM 节点数偏移。

真空样本显式提供 [0,3]/[0,1] 空数组和 count=0。一个 batch 混合真空与有环境样本时也提供一致键集合；缺失力标签使用零权重与形状正确的占位值。

MM 不是 MACE 原子节点，不加入 node_attrs、QM edge_index 或 E0s 统计。QM–MM 点源耦合按图生成，避免跨图相互作用；首版不因 MACEPOL-EF 的输入形态而采用批内最大尺寸 padding。

扩展 `KeySpecification` 映射把外部字段放入 Configuration.properties，随后复用 AtomicData。extxyz 中的可变长 MM 元数据可沿 info 路径读入，序列化方式必须验证 round trip；不能放入要求长度等于 QM 原子数的 atoms.arrays。

### 7. QM/MM 力需要扩展内的统一求导函数

当前 `get_outputs` 仅接收一组 positions，不自动提供独立 MM 坐标导数。其内部 `compute_forces` 在推理时可能释放计算图，不能先调用它求 QM 力，再无条件第二次求 MM 力。

首版在扩展内提供一次对 `(qm_positions, mm_positions)` 的联合 autograd 求导，使用同一个总能量，返回 QM 力到标准 `forces` 键，MM 力到 `mm_forces`。training 时保留后续力损失所需的计算图；空 MM 返回形状 [0,3]。

位置是否开启梯度必须在静电特征构造之前确定。即使仅请求能量，内部电子优化仍需要对 state 求导；区分模型参数求导、坐标求导和内部求解梯度。`training=False` 不能等价成整个求解器 `no_grad`；暂不支持直接包在 inference_mode 中运行。

首版不给总能量编造唯一的逐原子分配，`node_energy` 可为 None，并在专用 calculator 中不声明 per-atom energies。模型保留标准 energy/forces，额外给出 base_energy、env_energy、vacuum_correction、charges、atomic_dipoles、mm_forces 和求解诊断。

### 8. 训练接线：复用 MACE 训练器，独立组装配置

当前贡献指南与现有 CLI 的模型白名单都倾向于独立扩展组装。首版建议由 envhead/workflow 提供薄入口，复用现有数据工具、训练循环、checkpoint handler、优化器/调度器模式；不复制训练引擎或建立另一套训练框架。可用 setup.cfg 的加性 entry point 暴露命令，具体名称在实施时确定。

与现有训练循环保持 `loss(ref, pred, ddp)` 和 forward 关键字兼容。普通 E/F 使用现有损失函数；新增 MM 力与配对项由 EnvHeadLoss 组合，并遵守现有权重/分布式归一化语义。第一阶段先接通独立真空/嵌入 E/F/MM 力；配对差值需要 sampler 保证关系，不在 loss 中依赖随机 batch 恰好包含同一组。

现有训练器仅传通用 force 标志，首版在请求力时同时返回 MM 力，无需给共享训练循环添加新分支。额外诊断表由扩展 evaluator 输出，保留 MACE 默认 E/F 指标。DDP、EMA、SWA 的具体兼容性依次验证；尤其不在未检查时启用改变可训练参数集合的后处理。

最少的新增配置分组为：foundation 路径与能量头选择、env_head 结构、response_basis、energy_model、solver、MM 字段、loss。已有 cutoff、irreps、correlation 等参数沿用 MACE 语义。先支持 e3nn/PyTorch eager，不同时承诺 cueq、oeq、compile 或 TorchScript。

### 9. checkpoint 与 ASE calculator

head-only checkpoint 包含：格式版本、env_head state_dict、head 配置、关键模型元数据、单位/密度基约定、归一化统计、求解配置。加载时验证配置与参数形状；checkpoint 不缓存某个构型的 SCF 状态。

训练恢复另外保存 optimizer、scheduler、epoch 等，沿用 MACE checkpoint 机制。完整打包模型与 head-only 模型分开定义；当前 `extract_config_mace_model` 使用精确类名白名单，不会自动识别新子类，故扩展 io 显式负责配置 round trip。未来核心注册不能只加一个类名而漏掉 head 配置。

ASE 适配从普通 MACE calculator 的加载、设备、单位和结果映射借鉴，在扩展目录内实现仅声明 energy/forces 等已支持能力的 calculator。已有 calculator 默认会请求 stress，且结果键与模型类型有分支，不能未经适配直接套用。

MM 坐标/电荷是独立环境状态；setter 更新必须使 ASE 结果缓存失效。否则 QM 原子未移动而 MM 改变时可能复用旧能量。MM 力按自定义结果键返回，标准 ASE forces 始终只对应传入的 QM atoms。

### 10. 数值验收与实施顺序

A. 严格装配与原模型 E/F 对拍：关闭校准、空 MM，保留原标度、元素顺序与全部 base 权重；验证保存/重载。

B. MM 数据与静电算子：多图、空环境、源排列、正负号、q/μ 基转换、解析值与坐标有限差分。避免把包含大量 MM 伪节点的全图实现作为默认，先检查是否产生不必要的 MM–MM 二次成本。

C. 二次电子响应：约束线性解基准、联合 QM/MM 力、批处理独立性、求解容差；使用固定输入的数值测试。

D. 非线性网络与求导：当前状态重新嵌入、多体块、真空/嵌入两次求解、参数梯度与力损失。先小体系验证，再扩展隐式/Hessian-vector 求导。

E. 原生训练循环接入、head checkpoint、ASE 环境缓存；完成后逐项增加性能后端及应用范围。

不修改已有 `tests/golden/` 参考数字，不用只断言 forward 成功代替物理验证。按当前 pytest capability marker 规则处理可选依赖；小型确定性输入与新增参考数字放在 EnvHead 自己的测试目录。

本节保留设计推演；已实现范围和接口以第十一部分为准。


## 十、MD 引擎适配：模型接口与引擎职责

用户要求停止数据读入路径验证，本节仅进行接口设计与源码核对。部署目标包括 OpenMM-ML 和本地 MLMM4AMBER/sander；ASE calculator 只是辅助接口。

### 1. 为什么需要 MM 坐标导数

固定 MM 电荷表示 qMM 不进行电子极化；MD 中 MM 原子坐标 X 仍然变化。模型能量 Ebase(R)+c(R)+W(R,X,qMM) 产生

FML=−∂(Ebase+c+W)/∂R，FMM,embedding=−∂W/∂X。

这里对神经模型能量求导，不对 QM 软件反向传播。MM 侧标签不是基础训练的必需条件；它可由参考 pcgrad 提供额外监督，但部署在移动 MM 环境中必须计算对应力。完全冻结 MM 坐标的静态应用可不请求此输出。

引擎与模型有两种等价实现边界：模型直接接受 X/qMM 并返回两侧力；或者引擎构建外势特征 v，模型返回 ∂W/∂v，引擎以链式法则求 MM 力。后者要求外势基、单位、平滑、周期核和所有必要导数一致，不能只返回普通原子电荷就假定兼容任意多极响应。

### 2. 统一 runtime 合同

初始化信息：ML 全局索引、元素、Q/S、模型/单位元数据、MM 源的全局索引与电荷、边界规则。

每步输入：ML 与 MM 源位置、必要时的 cell/PBC 信息和环境选择映射。输出：完整 ML+嵌入能量、ML 力、MM 嵌入力、收敛状态；q/μ 作为可选观测量。

引擎负责 MM 内能及 ML–MM 非静电项。适配层明确移除已被模型替代的 ML 内部 FF 能量和 ML–MM 经典静电；模型不再额外叠加一次 base。源电荷从原始拓扑参数保存，不能从已经为排除交叉静电而修改的电荷数组误读。

### 3. OpenMM-ML

核对的[上游 mlpotential.py](https://github.com/openmm/openmm-ml/blob/main/openmmml/mlpotential.py)支持 potential-specific embedding 与 embedding plugin。默认 mechanical embedding 的接口不能自动提供 EnvHead 所需的环境输入和能量排除。

[上游 main 的 macepotential.py](https://raw.githubusercontent.com/openmm/openmm-ml/main/openmmml/models/macepotential.py)当前用 PythonForce callback：获取全体系位置后切出 ML subset，运行 MACE 并映射回全体系力。这里是上游 main 的源码状态，尚未核对本机 OpenMM/OpenMM-ML 版本是否有同一接口；不能混用旧版 TorchForce 说明与该实现。

拟增加 EnvMACE potential/embedding 适配：保留全体系坐标，从不同索引提取 ML 区与 MM 源；一次模型调用返回总 ML+嵌入能量以及两侧力，scatter 回 OpenMM 粒子顺序。虚拟点力需遵守 OpenMM 的映射流程，不能丢弃带电虚拟位点。

OpenMM 使用 kJ/mol、nm；MACE 数据路径通常用 eV、Å。适配层统一转换能量和力，特别注意力还含长度换算。明确读取含 head 的能量键，不能默认沿用可能只含 base 的 interaction_energy。

经典静电排除需要按实际 NonbondedForce、exceptions 和 PME 配置处理。首版非周期直和便于明确核对；生产周期环境必须设计实空间、倒空间、自项及相关修正的归属，不能只删除实空间 pair 就声称完成 EE。

若部署版本使用 TorchForce/LibTorch，则需要相应可导出的 runtime 包装。当前 Python eager 设计不等于已经可导出，后续应在训练大模型前确定目标引擎版本与求解器的执行路径。

### 4. 本地 MLMM4AMBER / sander

已读取本地 [mace.hpp](/home/hungn/Desktop/MyRepo/MLP/MLMM4AMBER/sander/mace.hpp)、[mace.cpp](/home/hungn/Desktop/MyRepo/MLP/MLMM4AMBER/sander/mace.cpp) 和 [mlp_potential.cpp](/home/hungn/Desktop/MyRepo/MLP/MLMM4AMBER/sander/mlp_potential.cpp)。当前 C++ MACE forward 接收元素、ML 坐标和原子数；process 返回该模型能量与 ML 力。所检查接口没有 MM 点电荷输入及独立 MM 力输出。

因此 EnvHead 接入需扩展 Fortran↔C++↔模型的数据合同，传入 MM 源数量、坐标/电荷与全局映射，返回对应 MM 嵌入力。当前导出模型用 torch::jit::load 加载，部分调用签名还包含 local_or_ghost，不能直接把训练得到的 Python EnvMACE 对象当成可替换文件。

## 十一、首版实现合同与使用方法（2026-09-08）

本节记录本轮批准的实现，限定前文较宽的候选设计。生产模块集中在
`mace-ena/mace/modules/envhead/`，测试集中在 `mace-ena/tests/extensions/envhead/`。
共享 MACE 模型、block 和训练器保持原样，`setup.cfg` 仅添加 `mace_env_train` 入口。

### 1. 结构与路线

`EnvMACE(foundation, EnvHeadConfig(...))` 继承 `ScaleShiftMACE`，完整 deepcopy
foundation 后转为 float64，冻结其参数，新增唯一可训练模块 `env_head`。
对于 float32 checkpoint，转 double 保留原存储数值，不恢复已经丢失的精度。
旧版 OFF23 没有 `heads` 时补充单头名称 `Default`；元素顺序、E0s、所有权重、
readout、scale/shift 均保留。当前只支持 eager 单头 `ScaleShiftMACE`。

显式 tap 位于最后 interaction 后、product 前，通过 `flatten_tap` 逆变换
MACE 的 `[N,channel,sum(2l+1)]` 布局，再由 e3nn Linear 投影。
几何图与 tap 对坐标仍可导；环境项在原 scale/shift 之后添加。

| charge_route | energy_model | 电子变量 | 求解 |
|---|---|---|---|
| multipole | nonlinear | 每原子 `[q,mu_x,mu_y,mu_z]` | 阻尼约束 Newton + 回溯 |
| multipole | quadratic | 相同 q+mu | 稠密 KKT 直接解 |
| qeq | quadratic | q | 稠密 KKT 直接解 |

其他组合报错。默认 channels=32、num_interactions=2、correlation=2，
隐藏表示为 `channels x (0e+1o+2e)`。非线性残差每次用试探状态重新嵌入，
经过原生 MACE `RealAgnosticResidualInteractionBlock` 与
`EquivariantProductBasisBlock`，最后为有界 `tanh` 标量读出。
当前 residual_bound=0.1 eV/原子，可配置；正局部刚度为 softplus + 0.1，
可配置 floor。此构造给出强制增长的能量下界，允许多个局部极小值。

二次部分为 `chi(R).p + 0.5 p^T [Kfull(R)+D(R)] p`，其中电负性和
正刚度由几何上下文学习，偶极线性项为等变向量。QEq 不需要电荷训练标签。
默认开启零初始化真空校准 `c(R)`；`vacuum_correction=False` 关闭。
总能量始终为 `Ebase+c+Gembedded-Gvacuum`，两种环境均求解内部电子态。

### 2. 密度、单位与求解边界

密度采用 `rho_i=q_i*g_sigma-mu_i.grad(g_sigma)`，g 为积分等于 1 的 Gaussian，
sigma 为每个笛卡尔方向的标准差，默认 1 Å。内部 Gaussian–Gaussian 宽度为
sqrt(2)*sigma，Gaussian–MM 点源宽度为 sigma。包括完整自能，不包括 MM–MM 能量。
外源耦合为 `q*V + mu.grad(V)`；符号来自对密度积分分部。

`electrostatics.py` 以 erf 径向核及其解析梯度/Hessian 组装所有 q/mu 块。
重合点用关于 r² 的 Taylor 展开，避免 norm 在原点的不可微问题。
自矩阵为 `C*diag(1/(sqrt(pi)*sigma), 1/(6sqrt(pi)*sigma^3),...)`，
C=14.3996454784255 eV Å/e²。单位为 eV、Å、e、eÅ；无量纲求解的
参考尺度固定为 1 eV、1 e、1 eÅ，随 checkpoint 保存。

参考库对拍使用 `graph_longrange` 的 Gaussian 自项和实空间单极能量。
其实空间实现含 `r+1e-6`，故该对拍允许 1e-6 eV 的误差；解析核与独立
约束消元是严格数值验收的依据。偶极块另由对独立标量 erf 核的自动微分对拍。

Newton 默认最多 100 次、缩放驻点残差 1e-8、能量变化阈值 1e-12 eV。
采用确定性二次解初值、阻尼和 Armijo 回溯；真空与嵌入分别求解。
接受驻点前检查电荷约束切空间正曲率，非有限值、失败下降或未收敛均抛出
`SolverError`。这只能证明找到通过检查的局部极小值，不能证明全局最小或跨步
状态连续。状态重连接使用变分 KKT 残差，与
[参考线性化代码](../../ref/mace-scf/mace_scf/utils/linearize_solve.py)的思路相同，
本实现求解的是能量驻点残差。支持一阶状态灵敏度及能量二阶混合导数，
不承诺任意高阶导数。

### 3. 数据与训练

`attach_environment(graph, mm_positions, mm_charges, forces=None,
force_weight=1, group_id=None)` 在已有 MACE AtomicData 上添加环境。
MM 不加入 ML 图。张量沿图拼接：`mm_positions[M,3]`、`mm_charges[M,1]`、
`mm_count[B,1]`；vacuum 使用空数组。没有 MM 力标签时填零标签和零权重，
避免混合 batch 缺键。group_id 以字符串保留；自动划分以整个 group 为单位，
没有 group_id 时要求显式验证集。

训练入口可直接调用 `training.fit(model,train_loader,valid_loaders,directory,...)`，
内部使用原生 `mace.tools.train.train`、WeightedEnergyForcesLoss 和 MACE checkpoint
文件管理。`EnvHeadLoss(ref,pred,ddp)` 添加可选 MM 力项。优化器检查可训练参数
恰好属于 env_head，使用 Adam 与 ReduceLROnPlateau。首版仅单进程。

运行方式（在 mace-ena，deepfield 环境中）：

```bash
python -m mace.modules.envhead.train \
  --foundation ../ref/Foundation/MACE-OFF23_small.model \
  --train-file TRAIN.xyz --valid-file VALID.xyz --output-dir RUN \
  --charge-route multipole --energy-model nonlinear --epochs 10
```

QEq 对应 `--charge-route qeq --energy-model quadratic`。
`--head-config config.json` 可覆盖完整 EnvHeadConfig 字段；`--resume` 恢复。
重新安装 editable 包后亦可使用 `mace_env_train`。

帧内 ML 能量/力沿用 `REF_energy`/`REF_forces`，可通过 CLI 改名；可变长 MM
数组在 `Atoms.info` 的 `mm_positions/mm_charges/mm_forces` 中，约定已是上述单位。
`graphs_from_atoms` 只映射已有数据；本轮没有运行文件读取验证、数据转换或 QM 作业。
能量标签应为指定的 QM+PC 能量定义，不包含 PC–PC 自能；若参考程序报告含该项，
必须在上游数据合同中处理，否则会学入错误的环境常数。

### 4. 保存与独立推理

`checkpoint.save_head(path,model)` 保存 head state_dict、全部配置、单位、密度和
求解约定。`load_head(path,foundation)` 校验格式和约定，
严格加载 head。训练恢复文件包含完整模型、Adam、scheduler、epoch 和 CPU Torch RNG。
不宣称任意外部 sampler/worker 或 CUDA 随机状态的逐位恢复。

```python
from mace.modules.envhead.checkpoint import load_head
from mace.modules.envhead.runtime import EnvRuntime

model = load_head("RUN/head.pt", foundation)
result = EnvRuntime(model)(atomic_numbers, ml_positions, mm_positions,
                           mm_charges, total_charge=0)
# result["energy"], result["forces"], result["mm_forces"]
```

runtime 接受张量或数组，不依赖 ASE Atoms 或 MD engine；非周期 ML 邻居搜索是
稠密参考实现。输出 energy 为完整模型能量，forces 对应 ML，mm_forces 对应输入 MM。
额外输出 charges、atomic_dipoles、vacuum_charges、base_energy、env_energy、
calibration_energy、两种内部响应能量、外源耦合 electrostatic_energy、
solver_iterations/residual/converged。`node_energy=None`，未定义逐原子总能量分配。

内部需要 autograd；支持外层 no_grad 下调用，但不接受 inference_mode、编译/JIT、
PBC、stress/virial、Hessian、边力、LAMMPS 等请求。float64 eager 为本轮支持路径。
未实现 MBIS、link atom、PME、加速后端或实际引擎 adapter。
引擎后续保留 MM 内部与交叉 LJ，替换已覆盖的交叉静电，并接收完整双侧力。

### 2. 参考实现究竟解决了哪些问题

本轮核对的本地 checkout：mace-ena `59ad3a4`（包含上一轮未提交扩展），
AMP-BMS `935f178`，graph_electrostatics `66ef875`。以下结论限定于所读路径。

**AMP-BMS：** [Simulator._modify_forces](../../ref/amp_bms/source/md/Simulator.py)
在初始化含 PME 的 System 之后，移除原非键合 Force 并建立 shifted reaction-field
与 LJ Force；ML 原子在经典静电中的电荷置零。模型的
[CoulombQMMM](../../ref/amp_bms/source/modules/Modules.py)在 md_mode 添加 RF 修正。
[ForceModule](../../ref/amp_bms/source/md/TorchForce.py)接收全体系位置、取出两侧坐标，
构造最小镜像距离并返回模型能量，通过 OpenMM-Torch 回传两侧力。
值得借鉴的是完整能量组装、双侧坐标图、邻居表和周期部署；其特定的删力逻辑
针对自身溶质/溶剂选择，不能直接用于任意蛋白活性位点分区。

其[预印本](https://doi.org/10.26434/chemrxiv-2026-kx9w0)明确采用 shifted RF，
Table 4 给出 ML–MM 极化 8 Å、ML–MM 静电/LJ 9 Å、MM–MM 9 Å。
这些值是该工作的部署配置；我们的 Gaussian 密度与数据定义不同，不能视为默认最优值。

**graph_electrostatics：** 已核对
[energy.py](../../ref/graph_electrostatics/graph_longrange/energy.py)与
[kspace.py](../../ref/graph_electrostatics/graph_longrange/kspace.py)，周期路径构造显式 k 向量、
密度 Fourier 分量和能量。适合 Gaussian 多极归一化、周期自项和显式倒空间对拍；
本轮没有看到该能量路径采用 FFT 网格 PME，不能以“支持周期”推断 PME 吞吐。
跨库 adapter 要统一 Cartesian 与实球谐顺序、归一化、半空间 k 求和因子和自项。
MM 点源应按点源 Fourier 因子处理，不能为适配库而悄悄赋予物理 Gaussian 宽度。

**torch-pme：** [官方仓库](https://github.com/lab-cosmo/torch-pme)列出单极 PME/P3M/Ewald，
偶极则列出标准 Ewald。可作为 QEq mesh 后端候选和偶极参考，不应预先宣称它能直接
处理我们的全部 Gaussian q+mu 混合核。其 CoulombPotential 的 smearing 用于 Ewald
分裂；这与本项目固定的物理 Gaussian sigma 是两个独立参数。
[官方实现说明](https://torch-pme.readthedocs.io/en/stable/_modules/torchpme/calculators/pme.html)

**Gaussian multipole + PME 已有先例：**
[pGM 工作](https://arxiv.org/abs/2007.10517)说明 Gaussian 多极可与 AMBER PME 结合，
并通过水盒 NVE 验证。这支持算法可行性；现成的能量参数化和耦合实现仍需逐项适配。

### 3. 电子态与分片约束先于引擎适配

审查时的首版在空环境下 W=0，因此同一几何的 Ebase+c 与输入 Q 无关；改变 Q 只改变电子态，
不能产生不同的真空电离/电子附着能。该 Q 通道缺失已在第十三部分修正。total_spin 虽存在于 runtime 输入，也没有进入
当前 OFF foundation 的 head。这是能力边界，不能依赖更多训练样本消除结构上的退化。

第一步为 model manifest 增加训练支持的元素、总电荷/多重度与分子类别范围。
仅支持指定电子态的模型，对未支持态拒绝；多电子态版本使用标量态嵌入条件化
几何—响应参数与真空校准 c(R,Q,S)。多重度与 S/2S 的命名必须统一，禁止混用。
若没有相应参考数据，增加条件输入也不能宣称获得跨态泛化。

QEq 的全局电荷守恒不保证分离极限。以两个相距 R 的位点、chi=(0.4,-0.3)、
局部 hardness=(2,2)、sigma=1 Å、Q=0 为诊断：包含当前 Gaussian 自项时，
R=10/100/1000 Å 的 q1 分别为 -0.04030324/-0.03506967/-0.03462011 e。
其渐近值仍非零。该例只说明普通全局 QEq 的结构性电荷转移自由度；没有把它作为 QM 真值。
理论依据见 [QTPIE](https://arxiv.org/abs/0807.2068)及
[分离灾难分析](https://arxiv.org/abs/0812.1543)。multipole 路线的 q 自由度同样需要检查。

修订约束为 C^T p=Q_groups：C 在对应原子 q 分量上取 1，mu 分量为 0。
每个模拟构型仍可共享一个空间图和完整静电耦合，但若干独立溶质分别守恒。
约束组来自稳定的化学分区/拓扑；不能按每步距离截断重新分组，避免约束突然跳变。
发生真实电荷转移的反应片段可合并为同一电子组，并通过反应数据验证。
首个引擎版本固定分区、无跨 ML–MM 共价键，不自动切换电子组。

按组中心化 chi 可去除 chi -> chi+C a 的规范自由度；该变换在真空与嵌入差值中
仅增加相同的 a^T Q_groups，不影响 W。响应电荷仍按潜变量/有效密度解释，
没有电荷标签时不自动等同于 MBIS 或其他原子电荷定义。

### 4. 三种边界模式，分别定义 Hamiltonian

统一记孤立溶质泛函 F0=U_theta+0.5 p^T K0 p，
G0=min_{C^T p=Q} F0。对边界 b 定义：

G_b(v)=min_{C^T p=Q}[F0+0.5 p^T DeltaK_b p+p^T v_b]。

模型能量为 Ebase+c+G_b(v)-G0。经典 MM 内部与交叉 LJ 由引擎另外持有。
可以输出两个清楚的分项：

- boundary_energy = G_b(0)-G0；
- embedding_energy = G_b(v)-G_b(0)。

它们的和就是总响应增量。这一分解用于解释与验证；实际计算总能量时不必
额外求一次 G_b(0)，除非明确请求该分项。

| 模式 | DeltaK_b | v_b 与几何 | 空 MM 语义 |
|---|---|---|---|
| isolated_direct | 0 | 当前非周期 Gaussian–点源直和 | W=0 |
| periodic_sources_rf | 0 | 有限且解包的 ML 溶质；MM 周期镜像 + 平滑有限范围外源核 | W=0；不含 ML 自身周期像 |
| full_periodic_ewald | K_periodic-K0 | ML 与 MM 均按明确的周期 Green 函数处理 | 仍有 ML 周期像/背景等边界能，通常非零 |

推荐顺序为第一行作为数值基准，第二行作为首个周期溶液 MD 版本，第三行作为
完整周期扩展。第二行是一种明确的有限溶质/周期环境模型，保留原 F0 的稳定性和
原真空标定；不能把它解释为与第三行等价。周期镜像、背景或 RF 边界是对远程电场
的模型处理，不引入逐个 MM 原子的可极化电子变量。

对于第三行，若分子复制到相邻晶胞后的短程化学接触很强，单加静电像修正无法
恢复 foundation 缺失的跨胞化学作用。因此其首个对象也应是充分溶剂隔开的有限分子，
不宣称已经覆盖晶体/周期共价网络。

重要修正：完整周期模型不应为了保留“空 MM 时等于 base”而随意减去全部周期像能。
若选择这种差值，只能声明模拟的是相对于周期真空的嵌入响应。
孤立真空、周期真空和热力学溶剂化基准必须分别标识。

### 5. RF/Gaussian 多极核：导数和稳定性不能跳过

首个 RF 版本保留内部 K0，修改外源 v；MM–MM RF 属于引擎。
外源标量核可候选为 S(r) T_sigma(r)，S 在短距离为 1、末端平滑降为 0，
并在中远程拟合/构造 shifted RF 行为。若采用这种构造，应明确称为有效
Gaussian/RF 耦合核；未经卷积推导，不能宣称严格等于 Gaussian 密度与理想 RF
Green 函数的卷积。确认核后固定物理参数，再进行训练/部署偏移评估。

所有多极块必须从同一标量 u(r) 的空间导数产生。AMP-BMS 的 md_mode 实现中，
B0=u_RF，B1=B0/r²，B2=3B1/r²。这是其实现的系数关系；对我们的导数型 Gaussian
多极基不能直接照搬，因为一般的 -u'(r)/r 不等于 u(r)/r²。
以其 RF 参数 rc=9 Å、epsilon=78.4、r=5 Å 为例，本轮解析计算得到：

| 径向系数 | 数值 / Å^-3 |
|---|---:|
| u(r)/r² | 0.00159440089 |
| -u'(r)/r | 0.00620166507 |

这个差别说明两种多极扩展的物理定义不同；它不等同于断言 AMP 的标量能量自动求导
不保守，也没有据此评判其论文的轨迹结果。

q+mu 内部核最高含标量核二阶空间导数，力含三阶导数；为避免截断处的力跳变，
新核的切换层至少保证相应三阶导数连续，建议选 C4 切换以留出训练导数余量。
不能只令电荷势在截断点为零。近场 Gaussian 宽度和远场 RF 截断是独立配置。

若未来将 RF 同时用于内部 K，任意截断/平移不自动保留 Coulomb 核的半正定性。
必须检查约束切空间谱及能量下界，不能继续直接沿用当前 Kfull+D 的稳定性论证。
这也是首个 RF 版本保留 K0 的理由。

### 6. 周期倒空间、PME 与 MM 反作用力的完整计算

周期算子需要分别提供 ML–ML 块 K_b、ML–MM 块 A_b，使 v_b=A_b qMM。
MM 点源固定，ML 密度物理宽度固定；不同 Gaussian 卷积宽度按源/接收组合处理。
MM–MM 块由引擎持有，模型不得重复加入其能量。

若通过完整静电模块提取交叉项，双线性性给出：
E_cross(p,qMM)=E_el(p,qMM)-E_el(p,0)-E_el(0,qMM)。
该式要求三次计算使用完全一致的 box、k0 约定、分裂参数、自项、背景与边界项；
实际部署优先直接算双线性交叉项，避免大能量相减和不必要的 MM–MM 成本。

以 Fourier 约定 exp(-ik.r) 为例，ML Gaussian 密度因子含
(q_i-i k.mu_i) exp(-sigma² k²/2) exp(-ik.R_i)，MM 点源无 Gaussian 因子。
该表示为独立倒空间参考提供直接入口；FFT mesh 版本必须证明同一极限。

MM 力有两种合法接口：

1. 核与模型处于同一个可微图，直接联合求导 R/X；
2. 引擎提供 v，head 返回共轭响应 a=dE/dv（本合同的收敛态为 p*），
   静电 provider 实现 pullback，把 -(dv/dX)^T a 回传给 MM。

第二种接口还须提供 R 导数；完整周期时 K_b 的坐标/box 导数也不能漏掉。
若未来额外网络显式读取 v，则 a 不再自动等于 p*，必须从总能量求导。
仅传入预计算的场、或者仅把更新电荷写回引擎，都不足以证明双侧能量/力闭合。

三维周期第一版选择明确的 tin-foil 边界与净电荷处理，优先中性测试盒；
带电体系必须记录 k=0/补偿背景约定及体积依赖。Ewald 分裂参数与物理 sigma 分开。
改变数值分裂参数时，收敛后的 E/F 应保持不变；改变物理 sigma 则改变模型本身。
NPT/virial 要待 box 导数与分项归属验收后开启，首个模拟目标为固定盒 NVE/NVT。

### 10. 求解器与规模：当前 dense 实现的使用范围

当前 multipole 状态维数约 4N，dense 矩阵内存为 O(N²)，直接分解约 O(N³)，
非线性还包含 Hessian 构造和多次试探网络调用。不能将 AMP 的蛋白吞吐外推到本实现。
先记录 N=16/32/64/128 等固定体系的 context、K/v、两次求解、力和传输耗时及峰值内存，
再选择首个可承担的 ML 区大小；不给未测量的原子数上限作性能承诺。

后续升级路径为同一算子接口上的 Kp、HVP、约束迭代线性解/预条件。
小体系 dense 保留为 oracle；大型模式不再构造完整切空间 QR 或逐行 Hessian。
QEq/二次先升级，非线性随后跟进。求导必须通过独立的收敛线性化验证，不能仅把
求解迭代 detach 后宣称参数/力训练仍正确。

诊断增加：约束误差、投影驻点残差、能量变化、曲率下界估计、KKT 条件数估计、
阻尼大小、回溯次数。局部误差近似 delta_p≈-H_tangent^-1 r_tangent，说明小残差在
低曲率处仍可能导致大的状态/力误差，验收同时扫描容差与力误差。

默认保持确定性冷启动。warm start 是后续加速项：比较不同到达历史、坐标回访与
冷启动解；若不同局部极小值产生可见 E/F 差异，需要定义分支选择政策。
不得静默将未收敛 nonlinear 切换为 quadratic，这会改变 Hamiltonian。
缓存可以复用几何或算子，但应以全部坐标、box、源/约束版本和模型版本失效；
仅缓存上一帧电子态不能改变同一输入的物理结果。

### 1. 参数化与约束

令 h 为从 foundation tap 投影后的等变几何特征，h0 为其 0e 标量通道，N 为图内
ML 原子数。新增 `charge_conditioner`：两层 SiLU MLP，输入 `[h0,Q/e,Q/(N*e)]`。
对同一几何计算差值

`delta = MLP(h0,Q,Q/N) - MLP(h0,0,0)`。

delta 产生各个 l=0/1/2 通道的标量 gain 与仅用于 l=0 的 shift。每个不可约表示
内部的所有分量乘以同一 `1+tanh(gain)`，仅标量通道加 shift，保证 O(3) 等变性。
逐原子几何标量参与调制，因此 Q 的作用可以随局部环境变化。
Q=0 时调制恒等；这不阻止原有几何网络学习中性体系的环境响应。

同一调制后的特征用于：真空校准 c(R,Q)、电负性/偶极线性项、正硬度，以及
非线性几何—电子多体网络。真空与嵌入求解均使用相同的 Q 条件，且均满足 sum(q)=Q。
总能量为

`E = Ebase(R;Q) + c(R,Q) + min_p[F(R,p;Q)+p.v] - min_p F(R,p;Q)`。

当 foundation 不使用 Q 时，其 Ebase 对 Q 不变；Q 相关真空差异可由 c 学习。
当 foundation 使用 Q 时，c 学习相对于该基础能量的残差。基础权重继续冻结。
真空校准仍零初始化，所以模型刚装配时不会凭空产生电离能；相关差异由参考标签训练。
关闭 `vacuum_correction` 后仍有响应条件化，但无电荷能力的 base 不会获得真空电荷态能差。

### 1. 对参考实现的准确定位

本地 `ref/MACEPOL-EF-evolved/README.md` 的 E_app 讨论针对逐原子非均匀场下
直接使用 `-sum_i (q_i R_i + mu_i).E_i` 的问题。均匀场的势可写为 `-R.E + C`，
一般非均匀场不满足这个关系。该分支 `mace/modules/extensions.py` 的实际代码
已经优先使用 `q_i external_potential_i`，缺少标量势时才回退到平均场近似；
因此不能仅依据 README 把当前分支概括为平均场方案。

原点变换、ML/MM 整体平移和固定 MM 时移动 ML 必须区分。非均匀环境中后者
可以产生真实能量变化与净力。单凭中性 ML 的能量随位置变化不能判定公式错误。
EnvHead 始终通过相对坐标计算 Gaussian 加权势与其梯度，耦合为
`sum_i(q_i Vbar_i + mu_i.grad_i Vbar_i)`，其中物理场是 `-grad Vbar`。
不会根据局部 E_i 构造 `V_i=-R_i.E_i`。

[MACE-POLAR-1 原论文 III.11](https://arxiv.org/html/2602.19411v1#S3.SS11)
报告未用响应标签训练的模型在 HR46 极化率上的误差。此结果提示应专门验证
响应性质，不能从架构具有极化通道或 E/F 测试通过推断其 DFT 响应精度。
该论文引言亦讨论传统全局 QEq 的解离分数电荷和尺寸相关过度极化问题。

### 2. 可选固定碎片电荷约束与条件网络

统一约束扩展为 `C.T p = Q_groups`，C 的每列对应一个非空电子组，仅单极分量
取该组的成员指示值。每个 ML 原子恰好属于一组；这些组由输入固定定义，
不随距离、邻居表或求解迭代自动变化。真空与嵌入态使用同一组约束。

TensorDict/Batch 的可选输入：

| 字段 | 形状 | 约定 |
|---|---|---|
| `charge_group` | `[N]` | 每图局部整数 ID，从 0 连续编号，拼批时保持局部值 |
| `charge_group_totals` | `[sum_g K_g]` | 按图顺序拼接各电子组总电荷，单位 e |
| `charge_group_count` | `[B,1]` | 每图电子组数 |

三个字段需同时出现；每图组电荷之和必须等于原生 `total_charge`。
省略三者时仍为每图一个总电荷约束。`attach_environment` 为省略组输入的样本
补齐单组字段，使真空/PC 和不同组数样本可以在同一批次训练。
该字段与用于训练集划分的字符串 `group_id` 完全独立。

薄训练映射使用 `frame.arrays["charge_group"]` 和
`frame.info["charge_group_totals"]`；不要求转换现有文件。
Runtime 增加同名两个可选参数，自动构造组数。例如两个分子各三个原子可传
`charge_group=[0,0,0,1,1,1]` 和 `charge_group_totals=[1,-1]`，同时
`total_charge=0`。实际分组和电荷必须来自体系定义，不能套用该示例猜测。

Q 条件网络输入改为原子所属组的 `[h_0e,Q_g,Q_g/N_g]`，并沿用减去零电荷
条件输出的构造；校准、线性项、硬度和非线性电子网络均使用相同条件。
单组退化为现有 `[h_0e,Q,Q/N]`。这避免仅由新增远离的独立分子改变已有组
的 Q/N 条件；基础模型的适用范围、跨组真实库仑作用和几何感受野仍需独立考虑。

固定各组净电荷阻止组间净电荷转移，同时保留组内电荷重排、偶极变化和组间
电场诱导。它适用于指定电荷态的非共价 ML/MM 体系；研究组间电荷转移或反应时，
须使用相应的电子组定义或发展其他电荷转移模型。不能宣称已经普遍修复解离极限，
也不能宣称组内长链 QEq 的极化率尺寸标度已解决。默认全图约束仍保留上述风险。

求解器 KKT、约束投影、切空间曲率检查和可微重连接均支持多列 C；二次路线
继续直接求解，非线性路线继续检查局部极小值，未增加全局最小保证。

### 3. 响应合同和验收边界

固定 R、组定义及 Q_groups，定义

`G(v)=min_{C.T p=Q_groups} [F(R,p)+p.T v]`。

对稳定、收敛且平滑的解分支，`dG/dv=p*`。取 C.T Z=0，且
`H=partial_p^2 F`，则

`dp*/dv = -Z (Z.T H Z)^(-1) Z.T`。

因此响应矩阵对称、半负定，并有 `C.T dp*/dv=0`。若外势加上
`C a`，电子态不变，G 改变 `Q_groups.T a`。在比较嵌入增量 G(v)-G(0) 时，
须说明是否同时改变真空参考的势零点，不能把带电态的 Q*C 能量偏移当作错误。
物理均匀场下负能量二阶导对应局部稳定的半正定极化率。

新增 `tests/extensions/envhead/test_response_contract.py` 检查：

- 三条配置中 `dE/dq_MM` 与输出有效电荷密度在 MM 点产生的势一致，
  同时检查 MM 源电荷响应矩阵；这针对完整 EnvMACE 能量，不只测独立求解器；
- 多约束下 ML/MM 双侧坐标力有限差分，真空和嵌入组电荷均满足输入；
- 混合组数 batch、单组兼容性、严格保存加载、非法分组拒绝；
- 组条件与分别处理各组的条件一致；两点 QEq 分离测试显示默认全局约束的
  非零远距电荷，以及显式固定组电荷对该通道的约束效果。

### 16.2 第一优先：有限精度下的受约束 Newton

在固定几何下定义 f(p)=0.5 p^T A p+(b+v)^T p+U(p)，约束 C^T p=Q。
令 Z 为约束切空间的正交基，r=Z^T grad f，H_T=Z^T H Z。
在局部稳定解附近，若 H_T 正定：

`r ≈ H_T delta_y`，`f-f* ≈ 0.5 delta_y^T H_T delta_y`。

因此残差仍可辨识时，两个完整能量之差可能已落入 float32 舍入尺度。
当前 `trial <= value + c*alpha*slope + 1e-15` 的固定余量不随 dtype/能量尺度变化，
且允许近乎不动的候选反复进入下一轮。先保留现有 KKT/Newton 框架，分步处理：

1. 将二次项和网络残差显式分开，增加用于步长检查的能量增量计算：
   `Delta f=(A p+b+v)^T s+0.5 s^T A s+[U(p+s)-U(p)]`。
   非线性部分优先逐原子相减后求和，避免先累加两个完整总能量再相减。
   这是同一能量的代数重排，不改变训练目标。它减少消减误差，但不能消除全部网络舍入误差。
2. 普通区域保留下降方向及 Armijo 检查。近收敛区只有在预计下降已低于可解释的
   浮点误差尺度时，才启用受控的残差下降补充检查：约束保持可行、步长有限、
   能量无超出舍入尺度的上升，并且投影残差有实质下降。用实际算术项尺度估计
   误差，不能简单使用任意常数能量偏置作为放宽依据。误差估计系数需由小型复现校准。
3. 补充检查的局部依据：精确受约束 Newton 方向满足 H_T d=-r，
   残差 merit `m=0.5||r||^2` 的方向导数为 `Dm[d]=-||r||^2`。
   这只支持近解且 Jacobian 非奇异时的局部进展；不是全局能量下降或全局收敛证明。
   求残差平方的驻点本身也不够，最终仍须原始驻点残差、电荷误差达标及切空间正曲率。
4. 增加无进展检测：候选状态不可辨识、残差持续不降时明确报告数值停滞。
   小步长或零能量变化不能单独触发成功；线搜索候选接受也不等于最终收敛。
   KKT 重连接修正后的实际返回态需复核残差/约束，避免只检查修正前状态。
5. 首轮保持当前显式残差阈值，不把误差估计直接用于放宽物理驻点要求。
   若不能满足，报告该 dtype 下的失败及尺度；不自动升精度或截断电子态。

参考：Ceres 的 [step control、trust-region 和 line-search 说明](https://ceres-solver.readthedocs.io/latest/nnls_solving.html)。
其问题形式是非线性最小二乘，此处只借鉴数值步长控制原则，以上能量分解与受约束
残差补充规则属于本项目拟议实现，需独立验证，不声称由 Ceres 直接提供。

### 16.3 第二优先：只在重连接时建立所需高阶图

当前每轮 Hessian 的每一行均 create_graph=True，构建了可继续求导的图，随后
搜索步却使用 hess.detach()；这些中间 Hessian 高阶图没有用于最终参数梯度。
拆成数值搜索和可微重连接两个阶段：

- 搜索阶段仍启用电子变量的 autograd：一阶梯度需支持构造 Hessian，但 Hessian
  行本身不建立继续求导的图；每轮释放不用的图。不能整体套 no_grad。
- 收敛点重新计算 f、grad、H 和 KKT 残差，建立能量/力 loss 所需的混合导数图。
  基础几何上下文和静电核到 QM/MM 坐标的路径必须保留，不能为省内存永久 detach。
- 保留参数/坐标到电子态的 KKT 线性化；不把普通前向数值通过当成力训练通过。
  最终稠密 Hessian 的存储成本依旧存在，本轮不承诺大 batch 的线性加速。

依据：[PyTorch autograd.grad 的 create_graph 语义](https://docs.pytorch.org/docs/2.14/generated/torch.autograd.grad.html)；
本地 [MACE-SCF 隐式求导说明](../../ref/mace-scf/docs/fixed_point_scf/implicit_diff.md) 与
[linearize_solve.py](../../ref/mace-scf/mace_scf/utils/linearize_solve.py)。
MACE-SCF 求解的是固定点残差，本项目使用变分 KKT 残差，不能直接照搬其 Jacobian。

增加验证 batch 进度、每 batch 真空/嵌入求解次数、迭代数统计、最大残差、

- 数值复现：受约束二次模型加小有界非线性项，解析/独立解或同一数学函数的

### 16.6 首项修复落实记录

后续远端异常确认出错于 vacuum、17 个 QM 原子、MM 数组为空、Q=-1。
新增 `test_solver_stagnation.py`：17 维正定二次项加 1e-3*tanh 有界残差，
float32、Q=-1、固定 seed 10。修改前在 8 步后仍残差未达标；修改后须达到
原始 1e-5 要求，并与同系数的独立 float64 Newton 数值解比较。

本次实现了受控残差补充接受规则：候选非零、步长至多 sqrt(eps)*(1+||p||inf)，
能量变化绝对值至多 8*eps*max(1,|f|) 时，要求实际投影残差平方下降并保持电荷
误差达标。此误差预算仅决定候选接受，不放宽最终驻点阈值；小步长门限避免单纯
增大常数能量偏置就允许大幅跳步。8 为当前有限精度保护系数，不是严格舍入误差上界。
正常可辨识下降仍走 Armijo。候选均无进展则抛出 stagnation，不能接受原状态反复空转。
完整能量增量的代数重排仍待后续实现，当前不声称已消除所有能量消减误差。

达标驻点先检查约束切空间正曲率；上一轮能量变化过大时，使用局部 Newton
decrement 估计剩余能量误差作为补充，而不是把上一大步永久当成未收敛证据。
KKT 可微重连接后复核实际返回状态残差和电荷约束。任一步失败仍明确报告。

搜索阶段 Hessian 行使用 create_graph=False，收敛处重新构建 create_graph=True
的 KKT 重连接图；电子变量的一阶求导和几何梯度路径保持。
空环境复用和 batch 诊断汇总尚未在本次落实。远端 CUDA 停滞样本尚未实机复验，
小型数值复现通过不等同于整套 GPU 训练通过。

### 16.7 验证高阶图显存问题与求导分流

后续 CUDA 栈在首次验证的收敛点 derivatives(create_graph=True) 内 OOM，
PyTorch 实际分配约 92.98 GiB，未分配保留约 0.65 GiB。主要可见开销为活跃
高阶计算图，而非仅 allocator 碎片；此栈未进入验证指标汇总。

固定 Q、固定 C 时，C^T dp*/dR=0；驻点 grad_p f=-C lambda，因此
`dG/dR = partial_R f + grad_p f^T dp*/dR = partial_R f`。
将该包络公式用于验证/普通一阶求力：电子态收敛并复核后 detach，重新计算
f(R,p*) 的显式坐标依赖，保留几何/密度核对 QM/MM 坐标的梯度，不建立可微 Hessian。
数值搜索仍需要电子变量的一、二阶导数，不能整体 no_grad。

力训练需要对力再求参数导数，保留原可微 KKT 重连接。纯能量模式 compute_force=False
也保留重连接以兼容显式响应求导。普通验证返回的 q/mu 不携带状态灵敏度图。
这不支持随坐标变化的电荷约束；有限驻点残差造成的一阶力误差须用对拍检查。
新增 float32/float64 一阶双侧力与训练路径对照，并检查验证路径不调用可微 Hessian。
入口统一使用 --batch-size 控制训练与验证，不保留验证专用 batch 参数。训练高阶图的规模问题仍然存在，
本改动不承诺 batch 128 可训练，也未实测远端 GPU 峰值内存。

空环境复用后续已落实：仅 M=0 时复用同一可微真空态及能量，新增 solver_reused
标记，第二槽迭代数记为 0；不对存在但电荷为零的外源走该分支。
针对性检查实际求解次数、零环境能量抵消、真空/嵌入电荷一致和零源电荷导数。

### 16.8 Hessian 导数行的分块向量化

逐行 autograd.grad 改为以单位基向量为 grad_outputs、is_grads_batched=True 的
分块 VJP，每块最多 8 行。数学对象仍为 d(grad_p f)/dp，chunk 只控制执行和
中间 batch 维的存储；不改变物理能量、收敛阈值、foundation dtype 或数据 batch。
参考本地 MACE-SCF linearize_solve.py 的 batched VJP 思路，本项目保留分块以控制
中间张量开销。该项不解决跨构型串行、最终稠密 Hessian 规模和所有 GPU 同步开销。

新增 float32/64 Hessian 数值与参数导数对拍，连同 MACE 双侧力、力损失梯度、
独立展开参考共 6 项通过。尚未对远端 GPU 吞吐量或显存进行实测，不承诺加速倍数。
EnvHead 侧 ProgressDataLoader 继承原生 DataLoader，为训练/验证各 batch 输出
开始、结束和消费耗时，不复制原生训练循环，不额外执行验证或扫描数据。

### 17.1 选择依据与适用边界

本节提出新的 nonlinear 内部表示，旧 checkpoint 的 nonlinear 含义不能被静默改变。

### 17.2 将多体几何计算移出电子态循环

每次构型前向：foundation tap -> Q 条件化 -> 两层 MACE interaction/product
-> 几何上下文 h。h 不依赖试探电子态或 MM 源，真空和嵌入共享。
这些新增 MACE 层属于 env_head，保留参数梯度和坐标梯度；缓存仅限本次前向，
不能 detach，不能跨优化器更新或 MD 步缓存。

h 产生线性项、正硬度、校准以及下述非线性系数。仍保留几何局域多体表达，
电子状态在短程邻域内耦合，完整 Gaussian Coulomb 提供长程耦合。
迭代内只执行稀疏收集/归约、小张量收缩、标量非线性和线性代数。

### 17.3 可明确求导的非线性能量候选

使用固定单位将 p=(q,mu) 写成无量纲 x=S^{-1}p，电荷尺度为 1e，
偶极尺度为 1e Angstrom。所有 K、b、v 和约束须按 S 一致变换。
以下矩阵和向量均处于 x 坐标：

    F(x) = 1/2 x^T A x + b^T x + U(x)
    U(x) = sum_(i,a) a_ia tanh(z_ia)
    z_ia = beta_ia + l_ia^T x + 1/2 x^T B_ia x

A 为 Gaussian Coulomb 加正硬度；a、beta、l、B 由 h 条件化。
每个 z 仅作用于中心及 cutoff 内邻居，B 对称，按局部收缩实现，不存储
每个通道一个全体系稠密 B。每个原子通道数起点为 16，后续以精度/耗时评估调整。
令 a_ia=(residual_bound/Kchannels)*tanh(raw_a_ia)，保证每原子残差有界。

不变量构造必须由明确的 O(3) 收缩定义：q、几何 1o 向量与 mu 的内积、
mu 的模平方、以及平滑邻域聚合后的同类标量。向量系数用 1o 输出，
标量系数用 0e 输出，边权带平滑 cutoff。不能直接把 Cartesian 分量送进普通 MLP。
模平方通道必须保留：孤立原子或高对称构型没有非零几何向量时，仍需表达
各向同性的非线性偶极响应。邻域聚合后再取模平方产生跨邻居电子态耦合。

以 t=tanh(z)、d=l+Bx 为例，单通道精确导数为：

    grad U = a (1-t^2) d
    Hess U = a [-2t(1-t^2) d d^T + (1-t^2) B]

这使 Hessian/HVP 无需通过 MACE product 做电子变量的二阶自动微分。
系数依赖坐标和参数，以上公式仍用可微 PyTorch 运算实现；力训练继续对
这些表达求混合导数。保留自动微分计算 F 的电子导数作为小体系数值对照。

有界 U 加正定二次项保证固定有限构型/外场下能量下有界，并不保证全局凸性、
唯一驻点或全局最小值。现有 Newton 实际只能返回经残差与局部曲率检查的
稳定驻点；若出现多个分支，G 的全局 min 解释需要另行验证。小幅非零初始化
结合二次态初值；不以裁剪电荷或放松残差来隐藏失败。

### 17.4 求解和训练先保持可对照

第一步继续使用带约束稠密 Newton/KKT，替换电子导数获取方式；这样可以独立
衡量网络拆分和解析导数的收益。不能同时换网络、求解器和反向算法后仅报告总时间。
接口依次为 geometry context、energy/gradient/Hessian(or HVP)、constraint solver、
能量组装。对应 modules 内小模块，head.py 负责组装，train/data 不复制求解逻辑。

训练继续使用收敛态 KKT 重连接，验证普通求力继续使用包络路径。
单次重连接的适用混合导数必须沿用独立展开/有限差分对照，不推广到任意高阶导数。
HVP/伴随 Krylov 为下一阶段候选，取决于真实 profile；非凸曲率下不能直接
无条件使用 CG。完整 Coulomb 矩阵及当前逐构型循环仍有规模限制。

带 PC 的构型仍需两个状态；空 MM 复用保持。真空样本环境差严格抵消，
仅靠这些样本不会训练出响应分支，需由 PC 样本提供响应监督。
初版仍采用确定性二次初值；真空解给嵌入解热启动会影响非凸分支选择，暂不默认启用。

### 17.8 训练中 float32 近收敛停滞的修正

远端 geometry 日志在 epoch 1 后下一轮 batch 19 中断：vacuum、53 原子、Q=2，
残差1.955e-5，阈值1e-5。复制的 epoch-1 checkpoint 确认为 float32、geometry、
32几何通道、16响应通道、86次optimizer更新；缺少失败前18个batch更新后的状态，
不能据此声称精确复现远端失败点。

代码审计及独立53原子Q=2合成问题（seed=0）发现两项可修复的数值不一致：
1. Newton使用解析电子梯度，但merit与最终检查使用autograd；两种等价收缩的
   float32舍入不同。统一使用同一 derivative_fn，旧网络仍使用autograd。
2. 达标后KKT重连接额外移动状态，舍入可使残差反而增大。改为零数值重连接
   p_connected=p_star-(delta-delta.detach())，保存达标状态，保留原KKT导数路径。
   继续复核返回状态；仅在原残差和局部正曲率检查通过后进入重连接。

合成复现旧路径stagnation=1.022e-5；只统一梯度后重连接残差=1.772e-5；
两项修正后原1e-5阈值通过，和同系数float64参考解对拍通过。
17项数值回归通过，包括旧求解器、电子Hessian/HVP、双侧力、力损失参数
有限差分、隐式导数与展开对照。没有改变dtype、阈值、能量模型或batch-size。
这些修正不消除所有float32精度限制：其他合成系数仍可出现真实停滞，必须保持
显式失败；若远端仍失败，应保存失败当步模型/构型分析尺度与条件数。

### 17.10 实际失败快照审计：约束修正与能量回溯

已读取复制的response_failure.pt：embedded，45 QM/463 PC，Q=1，CUDA
float32，PyTorch 2.11.0+cu126，matmul_precision=highest，TF32关闭。
现场残差1.144409e-5，电荷误差2.384186e-7。以下为CPU独立数值审计，
未宣称原CUDA完整回溯序列逐位重现。

- 保存电子态在CPU float32给出同样的1.144409e-5残差；完整Newton候选
  残差降至4.291534e-6，但原始能量变化为+1.907349e-6 eV。
- 约束切空间Hessian特征值约0.577475至70.07625，条件数约121.35；
  本现场没有发现负曲率或严重病态。最大|q|=0.54754e，最大偶极模=1.33588eA。
- 从保存初值在CPU float32独立重放成功（2步，残差3.33786e-6），说明
  CPU/CUDA舍入路径会影响近收敛接受；不能把CPU成功当作远端已经修复。

将保存的数值系数转为float64仅作诊断（foundation/head训练dtype不变），
先将A对称化以对应二次能量0.5*p^T*A*p。原A最大不对称量5.96046e-8，
电子解析梯度与能量AD的双精度差约3.25e-8，也应在实施时保持对称一致性。
现场电荷偏差为-2.533197e-7e，乘子lambda=-6.9220447，完整Newton步有：

    delta_charge = +2.533197e-7 e
    delta_F       = +1.7531157e-6 eV
    lambda*delta_charge = -1.7534906e-6 eV
    delta_L       = -3.7489096e-10 eV

其中L=F+lambda*(C^T*p-Q)。电荷可行性修正贡献的原始能量变化远大于切空间
优化收益。当前代码以F下降检查包含可行性修正的步，再由经验roundoff预算
允许残差下降，是一个已证实的判据不一致；本次证据支持优先修整这一模块。
独立双精度参考状态残差5.33e-15，与保存状态最大分量差8.47926e-6；
此比较只涉及电子状态，不能替代QM/MM力误差验证。

建议修整顺序：
1. Gaussian/response二次矩阵显式保持对称，保证能量、解析梯度和KKT对应。
2. 为几何表示提供稳定的能量增量计算，避免直接相减两个总能量；检查固定乘子
   Lagrangian增量或另一个明确兼顾可行性的merit函数，并统一方向导数。
   可行性修正仍受独立电荷残差检查，不能只允许任意原始能量上升。
3. 对本快照验证候选接受、最终驻点/电荷残差以及参数混合导数，再回归旧例。
   若仍有残差尺度问题，另行设计缩放判据；不预先提高绝对阈值。

数据侧另有独立发现：最近QM-PC距离0.2389463A，4对距离小于0.5A。
最近对为0-based QM index44、PC index192，PC电荷-0.4157e。固定1A Gaussian
核仍有限，不能据此归因电子求解发散；但真实QM+pc边界和强力标签值得核查。
快照没有元素/原始log身份，暂不能判定该QM点是否为cap/link H或是否应去除PC。

本节为审计结果；本轮未改变求解算法、训练精度或阈值。

### 17.11 对实际快照实施修复

geometry ResponseEnergy 显式对称化 A，使二次能量与解析梯度/Hessian一致。
新增 energy_change：二次项用 (Ap+b+shift)^T*d+0.5*d^T*A*d；
非线性项以精确的 dz 和 tanh 加法恒等式求增量，较大 dz 使用直接差避免
饱和时恒等式分母消失。shift=外源+C*lambda，lambda 在当前回溯内固定。
Newton 的方向导数同步使用投影梯度，候选独立满足电荷容差。
近舍入范围继续要求实际残差平方下降，防止小能量噪声被接受后导致循环；
仍拒绝无进展或不满足驻点阈值的结果。旧 state_mace 无解析增量，保留其原路径。
delta_energy 诊断在 geometry 路线中现在记录 Lagrangian 的增量绝对值。

实际失败快照在CPU float32由保存初值重放：一步达到残差2.384186e-6，
电荷误差5.960464e-8，Lagrangian增量绝对值约4.764e-10；未作CUDA复验。
没有修改dtype、配置阈值、网络权重格式或Gaussian宽度。

EnvHeadLoss 提供可加的 validation_components（能量、QM力、MM力各自的
加权平方误差和/计数），原生MACELoss通过可选接口累计并计算全验证集目标；
未实现该接口的原生损失保持原行为。反向loss不变。恢复checkpoint增加独立
validation_loss_version标记；旧文件恢复时保留optimizer/LR/进度，重置plateau
历史best/bad_epochs/cooldown，避免与旧缩小的指标比较。

新增验收包含可行性修正导致原始能量上升但Lagrangian下降的数值例、非线性
增量与能量差对拍、不等长batch划分的验证loss一致性，以及旧scheduler基准迁移。
